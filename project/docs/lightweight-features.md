# 轻量功能与免费额度验收（2026-11-10）

## 已实现与开关

元数据搜索、标签筛选、更新日志和私密投稿可上线。改密、永久注销的实现及本地事务测试已具备，生产开关保持关闭。运行时仅当目标 Pages 环境明确配置 `ACCOUNT_CHANGE_PASSWORD_ENABLED=1` 或 `ACCOUNT_DELETE_ENABLED=1` 才能分别启用；默认缺省为关闭。不得在未取得预览 CPU 数据时启用，不得修改密码哈希参数以换取通过。

当前连接查询账户订阅返回 403（需要 Billing Read，现有 OAuth 不支持）；历史 Workers 分析查询返回空样本。未开通付费，也未将空样本解释为零使用量。不能据此保证当前套餐或全站容量。

免费预算参考：Workers 每日 100,000 次、每请求约 10ms CPU；D1 每日读取 5,000,000 行、写入 100,000 行。参考官方 [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)、[D1 pricing](https://developers.cloudflare.com/d1/platform/pricing/)。现有所有静态资源经过 Worker，均纳入请求预算。

搜索在浏览器执行，不因输入关键词访问服务器，不发送或持久化关键词。索引只随已鉴权的搜索页和 RSC 下发；增加页面下载和解析量，不增加逐字 D1 查询。日志是随构建发布的内容。投稿无附件、外链抓取或后台轮询，列表分页 20 条，作者与状态查询有索引；每账号每日 3 次、待处理最多 5 条、每 IP 每日 20 次。

以 100 名日活、每人 10 页计算，每页若平均 20 个 Worker 请求，则约 20,000 请求/日；若平均 50 个，则为 50,000。这是情景预算，需加上其他站点、缓存命中、预取、失败重试和机器人流量，不能当作并发保证。上线后每周在控制台检查账户总请求和 D1 实际行读写；超过免费额度的一半时，先定位资源请求和重复调用，不自动付费。旧内容版本占用 D1 存储，保留仍被部署引用的版本，清理需单独确认。

## 账号功能上线门槛

预览中分别测量正常与错误密码、最长密码、并发改密/重置、存在多条关联记录的注销，每个主要场景至少 30 个平台 CPU 样本。目标 P95≤8ms、最大≤10ms、无 1102；网络耗时和本地单测时间都不能代替 CPU。暂缺有效数据，因此两个开关均关闭。管理员重置密码沿用原流程；用户界面显示未开放，不发布为可用功能。

生产不创建压力账号，不执行测试性注销。本地测试使用临时 Miniflare/D1，覆盖默认关闭、改密撤销会话与重置凭据、关联数据删除和事务失败回滚。

## 内容公告维护

在 project 目录运行 `npm run updates:prepare`，审阅 `.backend-build/update-candidate.json`，将确认内容并入 `content/updates.json` 的公告记录，再运行 `npm run updates:prepare -- --accept` 更新快照；将公告、快照和成稿一起提交。快照不包含全文，仅保存稳定章节编号、标题与内容指纹。

首次基线不公告全部存量内容。按章节合并语言版本，标题、摘要、正文、翻译和来源变化会产生候选更新；标签、日期、文件夹移动和 CRLF/LF 差异不产生更新。移除内容保留公告文字，不生成失效链接。人工填写功能变化，未开放功能必须明确标注。

## 投稿与账号数据

投稿只向本人和管理员显示，状态包括待处理、已采用、未采用。采用不自动发布；管理员仍须整理并复核，走现有 Markdown 发布流程。未采用投稿可由本人撤回；注销会删除全部原始投稿。已独立整理发布的笔记不会随账号删除，注销前有明确说明。

部署前先对预览和生产各自应用 `0005_submissions.sql`。迁移只添加表和索引，兼容旧 Worker。然后按 [发布指南](../RELEASING.md) 运行统一命令，确认匿名用户无法读取搜索元数据、投稿或账号设置。

预览浏览器：搜索输入“线性代数 矩阵”返回 33 个章节，输入期间 fetch 调用为 0，关键词未进入 URL。关于页更新日志可通过锚点打开。临时预览用户完成投稿与撤回，账号设置返回两个开关均为 false；没有执行生产改密或注销。页面资源条目样本为初始 11、稳定后 29（包含预取及 QA 查询），不能等同于独立实际网络请求或所有页面平均值。以 30 次/页估算，100 人每天 10 页约 30,000 请求，仍须计入其他流量；这不是已取得的全站容量保证。
