## 5.1 组合体的构成

### 一、什么是组合体

> **组合体：由两个或两个以上基本形体或简单形体，按一定方式组合构成的立体。**

![组合体概念](/course-materials/campus-engineering-drawing/figures/img_20261028_110541_4a2zxkxw.png)

> 前几章讨论的都是单一基本体（棱柱、圆柱等），而实际零件多由若干基本体叠加或切割而成，例如轴承座由轴套、支板、肋和底板组成。组合体是基本体与真实零件之间的过渡对象。

### 二、三种组合形式

#### 1. 叠加式

> **由若干基本形体像搭积木一样，按一定的相对位置关系叠加而成。**

![叠加式](/course-materials/campus-engineering-drawing/figures/img_20261028_110542_juimtt2z.png)

![三种构成方式](/course-materials/campus-engineering-drawing/figures/img_20261028_110534_p3854vxc.png)

#### 2. 切割式（挖切）

> **将一个基本形体按功能需要，切去若干基本形体而形成的组合体。**

![切割式](/course-materials/campus-engineering-drawing/figures/img_20261028_110548_vsmp8941.png)

#### 3. 综合式

> **是上述两种组合形式的综合形式，是既有叠加又有挖切的组合体。**

![综合式](/course-materials/campus-engineering-drawing/figures/img_20261028_110549_245i5pob.png)

> **强调**：**实际零件绝大多数是「综合式」**。  
> 所以做题时不要死盯一种 —— 往往是「先用形体分析法拆成几块（叠加），再对其中某一块用线面分析法看它被切成了什么样（切割）」。

### 三、表面连接关系（本章第一个核心考点）

> **连接关系：构成组合体的各基本形体的表面，会出现共面、相交和相切等关系。**

![三种表面连接关系](/course-materials/campus-engineering-drawing/figures/img_20261028_110544_1r4x2sah.png)

| 关系 | 含义 | 投影图上怎么处理 |
| --- | --- | --- |
| **共面** （平齐） | 两基本形体的表面**平齐连接** | **不画**分界线 |
| **相交** | 两形体表面相交， **表面交线是分界线** | **必须画**出交线的投影 |
| **相切** | 两形体的表面因相切而**平滑过渡** | **不画**线 |

#### 1. 共面（平齐）—— 不画分界线

> **共面：此时两面重合，在共面处两形体的相接表面之间不画分界线。**

![共面：平齐处不画分界线](/course-materials/campus-engineering-drawing/figures/img_20261028_110545_fdydfs8z.png)

#### 2. 相交 —— 必须画交线

> **相交：表面交线是它们的分界线，此时必须画出交线的投影。**

![相交：两表面相交处画分界线](/course-materials/campus-engineering-drawing/figures/img_20261028_110546_oj9mfggt.png)

#### 3. 相切 —— 不画线

> **相切：此时两面无明显交线，因此，在投影中的相切处也不应画线。**

![相切：相切处不画分界线](/course-materials/campus-engineering-drawing/figures/img_20261028_110547_j5vkouuu.png)

![三种连接关系：画线 / 不画线对照](/course-materials/campus-engineering-drawing/figures/img_20261028_110538_4oqk4dwq.png)

> 三种关系的判据是**该处有无真实的棱**：
>
> - 共面：两表面合成一个平面，中间无棱，不画分界线；
> - 相切：曲面与平面光滑过渡，无交线，不画线；
> - 相交：两表面相交产生交线，交线即棱，必须画出投影。
>
> 口诀：**共面不画、相切不画、相交必画**。判断看的是该处有无实际存在的棱线，而不是两形体是否相邻；不画的是两形体之间的分界线，形体自身的外轮廓照常画出。

### 四、5.1 小结

| 项目 | 要点 |
| --- | --- |
| 组合体定义 | 两个或以上基本形体/简单形体，按一定方式组合 |
| 三种形式 | **叠加** （搭积木）／ **切割** （削掉几块）／ **综合** （两者都有） |
| 三种连接 | **共面不画、相切不画、相交必画** |

## 5.2 组合体视图的画图与读图

### 一、两种基本方法（全书通用）

> **组合体画图的基本方法是形体分析法，常结合使用线面分析法。**

![形体分析法与线面分析法](/course-materials/campus-engineering-drawing/figures/img_20261028_110551_1xjw16q4.png)

|  | **形体分析法** | **线面分析法** |
| --- | --- | --- |
| **定义** | 假想将组合体分解为**若干简单形体**，研究各部分的形状及相对位置，再综合想象出其整体结构形状 | 将组合体看做由若干\*\*面（平面或曲面）、线（直线或曲线）\*\*按照一定规则围成，把组合体分解为若干面和线进行分析 |
| **主要针对** | **叠加**构形的组合体 | **切割**构形的组合体 |
| **地位** | **主力方法** | **辅助方法** （攻难点用） |

![两种分析法的分工](/course-materials/campus-engineering-drawing/figures/img_20261028_110537_t606fcci.png)

> 两种方法对应两种构形：
>
> - 叠加构形能看出明显分块，按块拆分最直接，用形体分析法；
> - 切割构形由整块削切而成，形状不规整，还可能出现截交线、相贯线，按块拆不出来，只能按面分析其形状与位置，用线面分析法。
>
> 实际作图先用形体分析法分块；某一块难以想象时，再对该块作线面分析。一开始就逐面分析，会把简单问题复杂化。

### 二、形体分析法画图（例：轴承座）

#### 1. 第一步：形体分析

> **轴承座分解为四个基本形体：轴套(Ⅰ)、支板(Ⅱ)、肋(Ⅲ)和底板(Ⅳ)。**

![轴承座的形体分析](/course-materials/campus-engineering-drawing/figures/img_20261028_110552_q7vtmk6s.png)

> 拆块可按功能判断：
>
> 1. 主体：体积最大、起支承作用的底板；
> 2. 功能件：完成主要工作的部分，如中间带孔、用于装轴的轴套；
> 3. 连接件：把功能件与主体连起来的支板；
> 4. 加强件：薄片状、三角形的肋。
>
> 机件中的组合体多可按「底板—功能件—连接件—加强件」四类拆开，这一顺序同时给出各块的相对位置。

#### 2. 第二步：确定主视图

> **主视图应尽可能多地反映组合体的结构形状特征，且应使其他视图上的虚线较少。**

![确定主视图](/course-materials/campus-engineering-drawing/figures/img_20261028_110553_e8fbzvz3.png)

> **选主视图的三条判据（按优先级）**：
> 
> 1. **形状特征**：能把零件「最有特点的那个面」摆正朝前（比如轴承座的轴套轴线要垂直于 V 面，这样主视图上轴套是个圆，一眼看出是「带孔的筒」）；
> 2. **虚线最少**：尽量让孔、槽的轴线垂直于投影面，这样它们在某个视图上聚成圆，别的地方就不用画一堆虚线；
> 3. **自然安放**：按零件在机器里的工作位置摆（不要倒着放）。
> 
> **常见错**：只看「哪边宽就朝哪边」，结果主视图上全是虚线，标记尺寸也麻烦。

#### 3. 第三步：画三视图

![画三视图（1）](/course-materials/campus-engineering-drawing/figures/img_20261028_110554_3oqawlim.png)

![画三视图（2）](/course-materials/campus-engineering-drawing/figures/img_20261028_110555_4p0648d2.png)

![画三视图（3）：画肋板、检查加粗](/course-materials/campus-engineering-drawing/figures/img_20261028_110556_c4vyuvoh.png)

> 画图顺序：**先大后小、先实后空、先轮廓后细节**。
>
> - 先大后小：先画底板等大块，再画立板、肋等小块；
> - 先实后空：先画实体轮廓，最后处理孔、槽，因为孔槽位置要靠实体定位；
> - 先轮廓后细节：先保证三个视图的外轮廓及「长对正、高平齐、宽相等」，再补内部细节。
>
> 每个基本体的三个视图应同时画出，不要画完一个视图再画下一个，否则容易失去投影对应关系。

### 三、线面分析法画图

#### 1. 例 7-2：导向块

![例7-2 导向块（面形分析）](/course-materials/campus-engineering-drawing/figures/img_20261028_110558_4vs90e13.png)

![导向块：画底稿](/course-materials/campus-engineering-drawing/figures/img_20261028_110559_r9nlgxen.png)

![导向块：检查、加粗](/course-materials/campus-engineering-drawing/figures/img_20261028_110600_o3i82bx3.png)

> **线面分析的核心动作**：**给每个面编号（P、Q、R…），逐个问三句话**：
> ① 这个面**是什么形状** （几边形？是平面还是曲面？）？  
> ② 它在三个视图上**分别是哪个线框**？  
> ③ 它是**哪个方向的面** （正平面/铅垂面/一般位置面…）？
> 
> 三句话答完，这个面的空间位置就定了。

#### 2. 例：滑块（切割体）

> **该形体是由一四棱柱被切去柱状形体 Ⅰ、Ⅱ、Ⅲ 而形成。**

![滑块的形体分析（切割体）](/course-materials/campus-engineering-drawing/figures/img_20261028_110601_1ek7d2sy.png)

![滑块：布图、画切割前的原形](/course-materials/campus-engineering-drawing/figures/img_20261028_110602_19hestb0.png)

![滑块：画切割形体Ⅰ、Ⅱ后的投影](/course-materials/campus-engineering-drawing/figures/img_20261028_110603_3jb5n5ck.png)

![滑块：画切割形体Ⅲ、检查加粗](/course-materials/campus-engineering-drawing/figures/img_20261028_110605_jhoecums.png)

> 切割体的画法是**先画完整原形，再逐刀切割**：
>
> ① 按完整四棱柱画出三视图；
> ② 按题目给出的切割顺序，每切一刀就在三个视图上同时修改对应的线；
> ③ 最后检查剩余轮廓与各视图的对应关系。
>
> 完整基本体的三视图是简单矩形，每刀只改动局部，比直接按最终形状描画更不易漏线。

### 四、组合体的读图（本章最难）

#### 1. 画图与读图的关系

> **组合体画图**：在平面表达空间的物体， **从三维到二维** （抽象思维）。  
> **组合体读图**：分析平面图形，想象物体空间结构形状， **从二维到三维** （形象思维）。

![画图与读图](/course-materials/campus-engineering-drawing/figures/img_20261028_110606_bl0plhc9.png)

> **要点**：**画图是"拆了再画"，读图是"看了再拼"。**  
> 两者用的是**同一套工具** （形体分析法 + 线面分析法），只是方向相反。

#### 2. 为什么必须多视图一起看

**一个视图能唯一确定物体的形状吗？—— 不能。**

![一个视图无法唯一确定形状](/course-materials/campus-engineering-drawing/figures/img_20261028_110607_95rym9tv.png)

**两个视图能唯一确定物体的形状吗？—— 也不能。**

![两个视图也无法唯一确定形状](/course-materials/campus-engineering-drawing/figures/img_20261028_110608_330ymbbc.png)

单个视图通常不能唯一确定形体。例如，L 形俯视图既可能来自 L 形平板，也可能对应带高度变化的构件。应结合已知视图，按长对正、高平齐、宽相等逐一对应线框，再补画第三视图。若三个视图仍不足以区分结构，可以采用其他表达方法。
#### 3. 线框和图线的含义（必背）

> **封闭线框**：物体上的**一个面**、 **两相切表面**或**槽与孔**的投影。  
> **图线**：物体表面有**积聚性**、两表面**交线**或回转形体**转向线**的投影。

![线框和图线的含义](/course-materials/campus-engineering-drawing/figures/img_20261028_110609_4e4jfwxo.png)

| 投影元素 | 可能是什么（按可能性排） |
| --- | --- |
| **一个封闭线框** | ① 一个**平面**的面；② 一个**曲面** （如圆柱面、球面）的轮廓范围；③ **两相切表面**合起来的一个投影；④ **通孔** （孔口）的投影 |
| **一条图线** | ① 两个面的**交线**；② 有**积聚性**的平面（面垂直于投影面）的投影；③ 回转体的**转向轮廓线** （轮廓素线）；④ 孔的**轴线** （点画线） |

一个封闭线框可能对应一个平面、一个曲面、两个相切表面的投影，或孔口。读图时先把线框与其他视图中的图线对应：若相应投影积聚为一条直线，检查是否为投影面垂直面。再结合其他视图中的轮廓及可见性判断曲面、平面或孔槽。

#### 4. 读图的基本方法

> **形体分析法（主）+ 线面分析法（辅）**

![读图的基本方法](/course-materials/campus-engineering-drawing/figures/img_20261028_110610_5pe2uidq.png)

| 方法 | 怎么做 |
| --- | --- |
| **形体分析法** | 用「**分线框、对投影** 」的方法分析出组合体由几部分组成，从**特征视图**入手，想象出各部分的形状、相对位置关系及组合方式，最后综合想象出整体形状 |
| **线面分析法** | 用「**分线框、对投影** 」的方法分析物体**各表面的形状**，从而想象出物体的整体形状 |

> **划重点**：两种方法的起手动作**完全一样** —— **「分线框、对投影」**。  
> 分出线框后，形体分析法着眼于基本体，线面分析法着眼于表面及其相互位置。
> 
> - 当成块 → 形体分析法；
> - 当成面 → 线面分析法。

#### 5. 形体分析法读图四步（背下来）

> **(1) 抓特征分解形体。**以主视图为主，配合其它视图，找出反映物体特征较多的视图，从图上将物体分解成几部分。  
> **(2) 对投影确定形体。**利用「三等」关系，划分出每一部分的三个投影，想象出它们的形状。  
> **(3) 面形分析攻难点。**当形体由切割方式形成时，常采用面形分析法对形体主要表面的形状进行分析，进而准确地想象出形体的形状。  
> **(4) 综合起来想整体。**抓住位置特征视图，分析各部分间的相互位置关系，综合起来想象出物体的整体形状。

![形体分析法读图步骤](/course-materials/campus-engineering-drawing/figures/img_20261028_110612_p2ai8sov.png)

> **四步串成一句话**：
> **「先分块 → 再对号 → 卡住了拆面 → 最后拼回去」**

![形体分析法读图举例：分线框](/course-materials/campus-engineering-drawing/figures/img_20261028_110613_gnah64ts.png)

![形体分析法读图举例：逐块对投影](/course-materials/campus-engineering-drawing/figures/img_20261028_110614_0aa0v0bw.png)

![形体分析法读图举例：综合想整体](/course-materials/campus-engineering-drawing/figures/img_20261028_110615_b45qenfr.png)

#### 6. 线面分析法读图

> 对于某些较复杂的形体，特别是**主要以切割方式构形**的组合体，原形在被逐步切割后所得到的形体结构不够清晰规整，甚至出现较复杂的**截交线或相贯线**。  
> 在形体分析的基础上，可运用**线面分析法**辅助分析局部的形状。

![线面分析法读图适用场合](/course-materials/campus-engineering-drawing/figures/img_20261028_110616_7y0ole56.png)

**例：压块（线面分析法读图六步）**

![压块：分析 Q、R 面](/course-materials/campus-engineering-drawing/figures/img_20261028_110619_lptofm42.png)

![压块：分析 S、T、U、V 面](/course-materials/campus-engineering-drawing/figures/img_20261028_110620_hbk021bm.png)

> **线面分析读图的技巧**：
> 
> 1. **先找回"原形"**：切割体的原形通常是个简单四棱柱，先把它的三个视图在脑子里补出来；
> 2. **给每个面编号**：P、Q、R、S、T、U、V…… 一个面一个面过；
> 3. **重点看"斜线"**：视图上每出现一条斜线，就对应一个**倾斜的面** （一般是投影面垂直面），这个面往往就是"切了一刀"留下的；
> 4. **最后拼**：所有面的位置关系理清了，整个形体的形状就出来了。

## 5.3 组合体的尺寸标注

### 一、四项基本要求（必背）

> **(1) 正确**：所注尺寸应符合**国家标准**中有关尺寸注法的规定，尺寸数字要**准确**。  
> **(2) 完整**：必须将组合体中各基本形体的**大小及相对位置完全确定**下来， **无遗漏，无重复**尺寸。  
> **(3) 清晰**：尺寸的**布局**应整齐、清晰，以便于看图。  
> **(4) 合理**：尺寸的标注应保证**设计要求**，还要尽量考虑到**加工、装配、测量**等工艺上的要求。

![尺寸标注的四项基本要求](/course-materials/campus-engineering-drawing/figures/img_20261028_110635_mt3qsptq.png)

> **尺寸标注的基本要求**：
> **正确、完整、清晰、合理**  
> 前三个是**图上能看出来的**，第四个「合理」是**工艺层面的** （要考虑怎么加工、怎么测量）。

### 二、基本形体的尺寸标注

**平面基本形体**：

![平面基本形体的尺寸标注](/course-materials/campus-engineering-drawing/figures/img_20261028_110636_c8nlcvym.png)

**曲面基本形体**：

![曲面基本形体的尺寸标注](/course-materials/campus-engineering-drawing/figures/img_20261028_110637_25ofijt9.png)

> **基本体标注的"够用原则"**：
> 每个基本体只要标**能唯一确定它形状的最少尺寸**即可，多了就是重复。

常见的最少尺寸：

| 基本体 | 最少尺寸 |
| --- | --- |
| 长方体 | 长、宽、高（3 个） |
| 圆柱 | 直径 φ、高（2 个） |
| 圆锥 | 底圆直径 φ、高（2 个） |
| 圆球 | 直径 Sφ（1 个） |
| 正六棱柱 | 对角尺寸、高（2 个） |

### 三、截切体和相贯体的标注（易错）

> **注意：不能在截交线上直接标注尺寸**，要标注**基本体的定形尺寸**和**截平面的定位尺寸**。

![截切立体的尺寸标注](/course-materials/campus-engineering-drawing/figures/img_20261028_110638_h3m229am.png)

> **注意：不能在相贯线上直接标注尺寸**，应标注**产生相贯线的两基本体的定形、定位尺寸**。

![相贯立体的尺寸标注](/course-materials/campus-engineering-drawing/figures/img_20261028_110639_o3l4iird.png)

> **为什么不能标在交线上？**  
> 因为**交线是"加工出来的结果"，不是"设计给定的尺寸"**。  
> 工人加工时，是照「基本体多大 + 从哪儿切一刀」来做的， **没人会去量那条曲线**。  
> 所以尺寸要标在\*\*"能指挥加工"的地方\*\*：基本体的定形尺寸 + 截平面的定位尺寸。

### 四、对称结构的标注（易错）

> **注意：不要直接从对称中心线引出尺寸界线进行标注，而应从两对称结构的"重要几何要素"引出尺寸界线进行标注。**

![对称体的尺寸标注（1）](/course-materials/campus-engineering-drawing/figures/img_20261028_110641_advuaih9.png)

![对称体的尺寸标注（2）](/course-materials/campus-engineering-drawing/figures/img_20261028_110642_tdodhlim.png)

> **例**：一个板上左右各一个孔，要标「孔心距」。
> 
> - **错误**：从中间那条对称中心线拉到右边孔心（只标了一半，加工时不知道左右孔是否真的对称）；
> - **正确**：**从左边孔心拉到右边孔心** （标出两孔的实际距离）。
> 
> **道理**：中心线是"假想的辅助线"，不是实物上真实存在的要素。 **尺寸界线必须从真实要素引出**，否则加工时没法对刀。

### 五、三类尺寸与尺寸基准（核心）

#### 1. 三类尺寸

> 组合体的尺寸分为**定形尺寸、定位尺寸和总体尺寸**三类。  
> **在组合体的长、宽、高三个方向上都应至少有一个尺寸基准。**

![组合体的尺寸类型](/course-materials/campus-engineering-drawing/figures/img_20261028_110644_frrzaj78.png)

| 类型 | 定义 | 通俗理解 |
| --- | --- | --- |
| **尺寸基准** | 确定尺寸起点的**点、直线、平面** | 「从哪儿开始量」 |
| **定形尺寸** | 组合体各组成部分**形状大小**的尺寸 | 「每块自己多大」 |
| **定位尺寸** | 组合体各组成部分之间**相对位置**的尺寸 | 「这块离那块多远」 |
| **总体尺寸** | 组合体外形的**总长、总宽和总高**的尺寸 | 「整个零件多大」 |

> **类比**：把组合体想成「一套家具摆在一个房间里」——
> 
> - **尺寸基准** = 房间的墙角（从墙角开始量）；
> - **定形尺寸** = 每件家具的尺寸（桌子 1.2m 长）；
> - **定位尺寸** = 家具离墙的距离（桌子离左墙 0.5m）；
> - **总体尺寸** = 整个房间占用的总空间。

#### 2. 尺寸基准的选择

> **一般是对称形体的对称面、形体的较大平面、主要回转结构的轴线和中心线等的投影。**

![尺寸基准的选择](/course-materials/campus-engineering-drawing/figures/img_20261028_110645_dxhhdqj4.png)

![三个方向的尺寸基准](/course-materials/campus-engineering-drawing/figures/img_20261028_110646_9hk06kj9.png)

> **基准选择的实用口诀**：
> **「长宽高，各一个；优先选：对称面、大底面、主轴线」**

| 方向 | 优先选什么当基准 |
| --- | --- |
| **长度方向** | 对称面 / 较大的端面 |
| **宽度方向** | 对称面 / 较大的侧面 |
| **高度方向** | **底面** （最常见）/ 主要轴线 |

> **三个方向都必须有基准**，而且**每个方向只能有一个主基准** （可以有辅助基准，但要少用）。  
> 漏了某个方向的基准，那一串尺寸就没有"起点"，加工时无从下手。

![三类尺寸实例](/course-materials/campus-engineering-drawing/figures/img_20261028_110535_75av21lx.png)

#### 3. 三类尺寸的实例（轴承座）

**定形尺寸**：

> 底板的长 100、宽 60、厚 20、半圆孔 R16 以及右前方的倒角 20；  
> 立板的长度 100、通孔 φ24、圆柱面 R24 以及板厚 20。

![定形尺寸](/course-materials/campus-engineering-drawing/figures/img_20261028_110647_31o6ntbt.png)

**定位尺寸**：

> 底板上半圆孔 R16 轴线的定位尺寸**50**，由**长度方向尺寸基准**引出；  
> 立板上通孔 φ24 的定位尺寸**48**，由**高度方向尺寸基准**引出。

![定位尺寸](/course-materials/campus-engineering-drawing/figures/img_20261028_110649_w9ffy7qb.png)

**总体尺寸**：

> 总长和总宽是底板的长 100 和宽 60。  
> **总高尺寸未直接标注**，是由于立板上方轮廓具有**回转结构**。  
> 总高尺寸可通过回转轴线的定位尺寸**48**和外圆柱面半径**R24**相加得到，即**72**。

![总体尺寸](/course-materials/campus-engineering-drawing/figures/img_20261028_110650_atduxx95.png)

> 回转结构的总高通常不直接标注。若同时标出总高与「轴线定位尺寸 + 半径」，三者构成封闭尺寸链，总高可由 $48+24=72$ 算出，属重复尺寸。标准做法是标轴线定位尺寸与半径，总高由加工者自行累加。

### 六、标注尺寸的要求（四条）

#### 1. 避免出现封闭尺寸链；回转结构总体尺寸的表达

![避免封闭尺寸链、回转结构总体尺寸](/course-materials/campus-engineering-drawing/figures/img_20261028_110651_b48ii8b8.png)

> **封闭尺寸链**：一串首尾相接的尺寸，最后一个尺寸能被前面的尺寸算出来 —— 这个「算得出来的」就是**多余尺寸**，必须去掉（或加括号作参考）。

#### 2. 平行尺寸的排列

> **相互平行的尺寸，应按大小顺序排列，小尺寸在内，大尺寸在外。**

![平行尺寸的排列](/course-materials/campus-engineering-drawing/figures/img_20261028_110652_547mg1bv.png)

#### 3. 同心圆柱的直径

> **同心圆柱的直径尺寸，最好注在非圆的视图上。**

![同心圆柱的直径标注](/course-materials/campus-engineering-drawing/figures/img_20261028_110653_acoup2c8.png)

> **为什么？**  
> 如果在圆视图上标，几个同心圆的直径线会**挤在一起、互相穿过**，看不清。  
> 注在非圆视图（矩形视图）上，可以一条一条平行排开，清晰得多。

#### 4. 突出特征、相对集中、布局整齐、尽量注在轮廓线外部

![标注尺寸的四项要求](/course-materials/campus-engineering-drawing/figures/img_20261028_110654_kt1uj94x.png)

> 尺寸布局的四条要求：
>
> 1. 相对集中：同一结构的尺寸尽量集中在一个视图上，如安装孔的定位尺寸 32、42、48 都标在俯视图；
> 2. 布局整齐：同一方向的尺寸对齐排列，如高度方向的 12 与 20、长度方向的 40、12、6；
> 3. 尽量注在轮廓线外部及两视图之间；
> 4. 突出特征：把最能说明形状的尺寸标在特征视图上，如轴承内外径 φ24 与 φ48。
>
> 常见错误四类：封闭尺寸链；平行尺寸顺序颠倒（大尺寸在内、小尺寸在外）；对称结构从中心线引出尺寸界线；把尺寸标在截交线或相贯线上。

### 七、标注尺寸的步骤（五步）

> **(1) 形体分析**：将整体的尺寸标注分解为对各组成部分的尺寸标注；  
> **(2) 选定尺寸基准**：选定长、宽、高三个方向的尺寸基准；  
> **(3) 标注定形尺寸和定位尺寸**：逐步标注各基本形体的定形尺寸和定位尺寸；  
> **(4) 标注和调整总体尺寸**；  
> **(5) 校核**：正确、完整、清晰。

## 5.4 作图方法与例题

> 本章题型只有三大类： **画三视图**、 **读图补视图**、 **尺寸标注**。  
> 每类都有作图步骤，下面给可执行的步骤 + 自查点。

### 一、题型 A：画三视图

> **① 形体分析 → ② 定主视图 → ③ 布图定基准 → ④ 逐块画 → ⑤ 检查加粗**

| 步骤 | 具体动作 | 关键点 |
| --- | --- | --- |
| ① | 拆成几个基本体，写下编号和名称 | **底座 + 功能件 + 连接件 + 加强件** |
| ② | 选主视图方向 | 形状特征最多 + 虚线最少 + 工作位置 |
| ③ | 画基准线、中心线，定三视图位置 | 三个视图**同时布图**，留出标注空间 |
| ④ | 每块**三视图一起画** | 先大后小、先实后空 |
| ⑤ | 擦多余线、按线型描深 | 重点查**共面/相切处有没有多画线** |

> **画图常见错误**：
> 
> 1. **共面处画了线** （应该不画）；
> 2. **相切处画了线** （应该不画）；
> 3. **漏画交线** （相贯线、截交线）；
> 4. **三视图对不上** （长对正/高平齐/宽相等没守住）。

### 二、题型 B：读图 / 补画第三视图

> **① 分线框 → ② 对投影 → ③ 定形状（卡住就线面分析）→ ④ 补线 → ⑤ 三视图互查**

| 步骤 | 具体动作 | 关键点 |
| --- | --- | --- |
| ① | 在已知视图上分出封闭线框 | 从**特征视图**入手 |
| ② | 用「三等」把每个线框对到另一视图 | 一一对应，注意保留 |
| ③ | 判断每个线框是**平面/曲面/孔/相切面** | 看它在别的视图上是一条线、一条曲线还是同样线框 |
| ④ | 按「可见实线、不可见虚线」补第三视图 | — |
| ⑤ | 三个视图来回对 | **每条线都要能说出它的来历** |

> **补视图的三条实战技巧**：
> 
> 1. **先补外轮廓，再补内部** （外轮廓定了，内部好放）；
> 2. **遇到斜线就是斜面** —— 斜线一定对应一个倾斜面，顺着它去找这个面的三面投影；
> 3. **用"切割还原法"**：如果补不出来，试着想「它原来是完整的什么形体，被切了哪几刀」。
> 
> **判断"多线/漏线"的终极方法**：
> 把每条线都问一遍「**你是哪个面或哪条交线的投影？** 」  
> 答不出来的线 → **多半是多画的**；反过来，如果某个面/交线**找不到对应线** → **漏画了**。

### 三、题型 C：尺寸标注

> **① 形体分析 → ② 定三个方向基准 → ③ 标定形 → ④ 标定位 → ⑤ 调总体 → ⑥ 校核**

| 步骤 | 具体动作 | 关键点 |
| --- | --- | --- |
| ① | 拆块（同画图） | 拆不出块的部分用线面分析补 |
| ② | 长/宽/高各定一个基准 | 对称面、大底面、主轴线 |
| ③ | 每块标**最少**定形尺寸 | 圆柱 φ+高、球 Sφ |
| ④ | 块与块之间标定位尺寸 | 从基准引，不从中心线引 |
| ⑤ | 补总长/总宽/总高 | **有回转结构时总高可不标** |
| ⑥ | 按「正确/完整/清晰/合理」四查 | 查重复、查遗漏 |

> **尺寸标注的自查清单（六条）**：
> 
> 1. **有没有重复尺寸**？（尤其封闭尺寸链）
> 2. **有没有漏基准**？（长宽高三个方向都要有）
> 3. **定形尺寸够不够确定形状**？（每个基本体都要能被唯一确定）
> 4. **定位尺寸够不够确定位置**？（每个块都要能定位）
> 5. **有没有标在截交线/相贯线上**？（必须禁止）
> 6. **平行尺寸是否小内大外**？ **同心圆是否注在非圆视图**？ **对称结构是否避开了中心线**？

### 四、本章易错点总清单

| # | 易错点 | 正确做法 |
| --- | --- | --- |
| 1 | 共面处画了分界线 | 共面**不画** |
| 2 | 相切处画了分界线 | 相切**不画** |
| 3 | 相交处漏画交线 | 相交**必画** |
| 4 | 认为一个线框 = 一个平面 | 线框可能是**平面/曲面/相切面/孔**，要对照其他视图 |
| 5 | 主视图随便选 | 选**形状特征最多 + 虚线最少**的方向 |
| 6 | 画图时逐个视图画完再换 | 每块**三视图一起画** |
| 7 | 补视图凭感觉 | **分线框、对投影**，每条线都能说出来历 |
| 8 | 尺寸标在截交线/相贯线上 | 标**基本体定形 + 截平面定位** |
| 9 | 对称结构从中心线引尺寸 | 从**实际要素** （孔心、边缘）引出 |
| 10 | 有回转结构还硬标总高 | 标**轴线位置 + 半径**，总高让工人算 |
| 11 | 出现封闭尺寸链 | 去掉一个，或加括号作参考 |
| 12 | 三个方向漏基准 | 每个方向**至少一个**基准 |

### 五、答题时间分配建议

| 题型 | 建议时间 | 主要耗时在哪 |
| --- | --- | --- |
| 画三视图（中等难度） | 12~15 min | 形体分析 + 逐块对投影 |
| 补画第三视图 | 12~18 min | 分线框 + 判断面/块 |
| 读图想形状 | 8~12 min | 卡在斜面/截交线上 |
| 尺寸标注 | 15~20 min | 查重复、查遗漏 |

> **作图检查**：**画图题一定要留 2 分钟检查三视图是否"对得上"**。  
> 对不上的直接表现就是「长对正/高平齐/宽相等」被破坏 —— 用尺子比一下立刻能发现。

## 课堂小结

| 项目 | 要点 |
| --- | --- |
| **组合体定义** | 两个或以上基本形体/简单形体，按一定方式组合构成的立体 |
| **三种构成** | **叠加** （搭积木）／ **切割** （挖去几块）／ **综合** （两者都有，实际零件最多） |
| **三种连接**  | **共面不画、相切不画、相交必画** |
| **判据**  | 问「该位置是否形成棱线？」摸得到→画，摸不到→不画 |
| **形体分析法** | 拆成**若干简单形体**；针对**叠加**； **主力方法** |
| **线面分析法** | 拆成**若干面、线**；针对**切割**； **辅助方法** （攻难点） |
| **画图流程** | 形体分析 → 定主视图 → 布图定基准 → 逐块画 → 检查加粗 |
| **选主视图** | **形状特征最多 + 虚线最少 + 工作位置** |
| **画图顺序** | **先大后小、先实后空、先轮廓后细节**；每块三视图一起画 |
| **切割体画法** | **先画完整原形，再一刀一刀切** |
| **画图 vs 读图** | 画图 = 三维→二维（抽象）；读图 = 二维→三维（形象） |
| **几个视图够**  | **一个不够、两个也不够，必须三视图配合** |
| **封闭线框** | 可能是： **一个面 / 两相切表面 / 槽与孔的投影** |
| **图线** | 可能是： **面积聚性 / 两表面交线 / 回转体转向线** |
| **读图起手** | **分线框、对投影** （两种方法动作相同） |
| **读图四步** | ① 抓特征分解形体 → ② 对投影确定形体 → ③ 面形分析攻难点 → ④ 综合想整体 |
| **尺寸四要求** | **正确、完整、清晰、合理** |
| **三类尺寸** | **定形** （自己多大）／ **定位** （离别人多远）／ **总体** （整体多大） |
| **尺寸基准** | 每个方向**至少一个**；优选**对称面、大平面、主轴线** |
| **截切/相贯标注**  | **不能标在交线上**，要标**基本体定形 + 截平面/基本体定位** |
| **对称结构标注** | **不从中心线引尺寸界线**，从实际要素引 |
| **回转结构总高** | **不直接标总高**，标「轴线定位 + 半径」 |
| **封闭尺寸链** | 必须去掉一个（或加括号作参考） |
| **平行尺寸** | **小在内、大在外** |
| **同心圆柱** | 直径**注在非圆视图上** |
| **标注五步** | 形体分析 → 定基准 → 定形+定位 → 调整总体 → 校核 |
