视图用于表达机件的外形，剖视图用于表达内部结构。本章讨论如何根据表达对象选择基本视图、向视图、局部视图、斜视图和剖视方式。

## 6.1 视图

> 本节的内容： **在三视图的基础上，进一步讨论采用基本视图、向视图、局部视图等方法表达机件。**

![本章学习内容](/course-materials/campus-engineering-drawing/figures/img_20261118_090232_zj9fmmdc.png)

### 一、基本视图（六个）

> **机件向基本投影面投射所得的视图称为基本视图。**  
> 除了**主视图、俯视图和左视图**之外，还有**右视图、仰视图、后视图**。

![基本视图：六个投影面](/course-materials/campus-engineering-drawing/figures/img_20261118_090234_ppf4wp2b.png)

| 视图 | 投射方向（从哪往哪看） | 投影面 |
| --- | --- | --- |
| **主视图** | 前 → 后 | V（正立投影面） |
| **俯视图** | 上 → 下 | H（水平投影面） |
| **左视图** | 左 → 右 | W（侧立投影面） |
| **右视图** | 右 → 左 | 右侧新投影面 |
| **仰视图** | 下 → 上 | 底面新投影面 |
| **后视图** | 后 → 前 | 后面新投影面 |

#### 六个视图的配置位置

> 六个投影面展开后各视图都有**固定的位置**，并且各视图之间的位置应符合「**长对正、高平齐、宽相等** 」的投影规律。  
> **各个视图在同一张图纸内按照以上规定位置配置视图时，可不标注视图的名称。**

![六个基本视图的展开配置](/course-materials/campus-engineering-drawing/figures/img_20261118_090236_avb1rf8h.png)

![六视图配置](/course-materials/campus-engineering-drawing/figures/img_20261118_090227_au0zw835.png)

第一角法下，仰视图在主视图上方，俯视图在下方，右视图在左方，左视图在右方。按图示配置，后视图排列在左视图右侧。

> **课件上的思考题答案**：**「找出形体的前表面在后视图中的位置」** ——  
> 后视图是从**后面**往前看，所以**物体的右面跑到后视图的左边去**了。  
> 也就是说： **后视图的左边 = 物体的右边** （与主视图成镜像）。

### 二、向视图

> **可以自由配置的视图称为向视图。**  
> 通常应在**视图上方用大写字母**标出名称，并在**相应视图附近用箭头指明投射方向，注上同样的字母**。

![向视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090238_fi9a4ohm.png)

向视图可以按图纸空间自由配置，箭头和字母用来指明投射方向并标识对应视图。
> 基本视图的位置是固定的，但有时候图纸排不下、或者想凑得更紧凑，就可以把它挪到别处。  
> **一旦挪了位置，就必须"挂牌"**：箭头指方向 + 字母对号。
> 
> **标注三件套（缺一不可）**：
> ① 原视图处画**箭头** （表示往哪看）；  
> ② 箭头旁标**大写字母** （A）；  
> ③ 挪过去的视图上方标**同样的字母** （A）。
> 
> **如果按基本视图的位置摆，就不用标**；一挪就得标。这是「按位可省、挪位必标」的规则。

### 三、局部视图

> **将机件的某一部分向基本投影面投射所得到的视图称为局部视图。**

![局部视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090240_kmui94mi.png)

> 局部视图一般要用**字母及箭头**指明投影部位及投射方向，并在局部视图上方标出对应的字母。  
> 局部视图的范围用**波浪线**表示。 **如果需要表示的结构是完整的且外轮廓为封闭图形时，波浪线可以省略。**

![局部视图的画法与标注](/course-materials/campus-engineering-drawing/figures/img_20261118_090242_6vh5wmtq.png)

**对称结构的局部视图可简化绘制**：

![对称结构局部视图的简化画法](/course-materials/campus-engineering-drawing/figures/img_20261118_090243_akrmfoi4.png)

> **局部视图的三个要点**：
> 
> 1. **只画一块**：其余部分不画（省时间）；
> 2. **用波浪线断开**：波浪线是"假想的断裂边界"， **不是物体的棱**；
> 3. **波浪线可以省**：如果这一块本身就是完整封闭的（比如一个凸台的正视图），就不用画波浪线。
> 
> **常见错**：把局部视图画成"半个机件"却不用波浪线断开 —— 会被判成"图形不完整"。

### 四、斜视图

> **当机件上倾斜表面的形状在基本视图上不能反映实形时，可增加平行于倾斜表面的辅助投影面，将倾斜部分向该面投射，所得到的视图称为斜视图。**

![斜视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090245_3bz61et7.png)

> 斜视图一般按**投影关系**配置，必要时也可配置在其它适当位置。  
> 在不致引起误解时， **允许将图形旋转**，但需要在视图上方**标注旋转方向符号**。

![斜视图的配置与旋转符号](/course-materials/campus-engineering-drawing/figures/img_20261118_090247_snbiki6a.png)

> **斜视图的关键理解**：
> 斜面上的圆/斜面上的实际形状，在正视图上会被"压扁"（不反映实形）。  
> 解决办法： **造一个新的投影面，让它平行于这个斜面**，再往上投 —— 这样就能看到实形了。
> 
> **和局部视图的区别**：

|  | 局部视图 | 斜视图 |
| --- | --- | --- |
| 投影面 | **基本投影面** （V/H/W） | **辅助投影面** （新加的，平行于斜面） |
| 解决什么问题 | 只想看**一小块** | 斜面**不反映实形** |
| 图形是否旋转 | 一般不旋转 | **允许旋转**，但要标旋转符号 |

### 五、6.1 小结：四种视图怎么选

| 视图 | 一句话 | 位置 | 要不要标注 |
| --- | --- | --- | --- |
| **基本视图** | 六个方向的"标准照" | **固定** | 按位配置**可不标** |
| **向视图** | 基本视图**挪了位置** | **自由** | **必须标** （箭头 + 字母） |
| **局部视图** | 只画**需要的那一块** | 一般按投影关系 | 一般要标（字母 + 箭头），范围用**波浪线** |
| **斜视图** | 为**斜面**专门造一个投影面 | 按投影关系，可平移/旋转 | 要标；旋转时加**旋转符号** |

## 6.2 剖视图

### 一、为什么需要剖视图

> **问题**：当机件的内部形状较复杂时，视图上将出现**大量虚线**，不便于看图和标注尺寸。  
> **解决方法**：采用**剖视图**。

![剖视图要解决的问题](/course-materials/campus-engineering-drawing/figures/img_20261118_090250_8sjijevp.png)

剖开后，原来被外部结构遮挡的棱边可直接显露，按可见轮廓画出。剖面线则标明剖切面经过的实体部位。

### 二、剖视图的概念

> **假想用剖切面剖开机件，移去观察者和剖切面之间的部分，将剩余部分向投影面投射，所得到的图形称为剖视图。**

![剖视图的概念](/course-materials/campus-engineering-drawing/figures/img_20261118_090252_joxhl4gn.png)

> **剖视图可简称为剖视，主要用来表达机件的内部结构。**  
> 采用剖视后，原有的**虚线变成实线**，再加上**剖面线**的作用，使内部结构的表达清晰、具有层次感，有利于画图、看图和标注尺寸。

![剖视的作用](/course-materials/campus-engineering-drawing/figures/img_20261118_090254_g4ooecva.png)

> **易错点**　剖切只作用于当前剖视图的表达。其他视图仍按完整机件绘制。

### 三、剖面符号与剖面线画法

> 画剖视图时，应在**剖切面剖到的机件实体部分**画上**剖面符号**。剖面符号随机件所用材料类别的不同而有所不同。

![剖面符号的画法](/course-materials/campus-engineering-drawing/figures/img_20261118_090255_hpndhnw0.png)

> 当**不需要在剖面区域中表示材料的类别**时，可采用**通用剖面线**来表示。  
> 通用剖面线一般采用与**主要轮廓或剖面区域的对称线成 45° 角的等距细实线**表示。

![通用剖面线](/course-materials/campus-engineering-drawing/figures/img_20261118_090257_v34n63p7.png)

**通用剖面线的两条规定画法**：

> **1\. 同一机件各视图中剖面线应画成方向相同、间隔相等的平行线。**

![剖面线规定（1）：同向等距](/course-materials/campus-engineering-drawing/figures/img_20261118_090259_x6fdaeh7.png)

> **2\. 如果图形中的主要轮廓线与水平方向成 45°，剖面线应画成与水平方向成 30° 或 60° 的平行线，但倾斜方向应与原图剖面线方向一致。**

![剖面线规定（2）：遇 45° 主线改 30°/60°](/course-materials/campus-engineering-drawing/figures/img_20261118_090301_rdcxz7vd.png)

> **要点**：
> **「45° 起步；碰到 45° 的斜轮廓，就让一让，改成 30° 或 60°」**。  
> 为什么？因为如果轮廓本身是 45°，剖面线也画 45°，就会**和轮廓线平行**，看起来像轮廓的延长线，分不清哪是轮廓、哪是剖面线。
> 
> **"同一机件"是关键**：同一个零件，不管画了几个视图、几处剖视， **剖面线的方向和间隔必须一致**；  
> 但**相邻的两个不同零件** （装配图中）必须**画成相反方向或不同间隔**，以示区别。

### 四、剖视图的画法要点

#### (1) 剖切面位置

> **剖切面一般应通过机件内部结构的对称面或孔的轴线，并平行于相应的投影面。**

![剖切面位置](/course-materials/campus-engineering-drawing/figures/img_20261118_090303_fj7l87gj.png)

以具有圆柱孔的机件为例，剖切面通过孔轴线时，能直接表达孔径及其轴向轮廓，便于标注。
> 如果斜着切孔，切出来的截面是椭圆，又难画又没意义。

#### (2) 剖切是假想的，其它视图仍要完整画出

> **由于剖切是假想的，所以一个视图取剖视后，其它视图仍应完整画出。**

![一个视图剖切后，其它视图仍完整画出](/course-materials/campus-engineering-drawing/figures/img_20261118_090305_3bwxf8xe.png)

> **课件原话："不能只画一半！"** —— 这是新手最常犯的错。  
> 俯视图剖了，主视图还是完整的；不要因为"已经切掉了"就把别的视图也画成只剩一半。

#### (3) 剖切面后面的可见轮廓线，应全部画出

![剖切面后面的可见轮廓线要全部画出](/course-materials/campus-engineering-drawing/figures/img_20261118_090307_cdz1wj75.png)

> **易错点**　剖切面后的可见轮廓仍需画出，包括台阶、孔口和退刀槽。
> 剖视图的"视"，本质上就是**站在切口处往里看**，看到的全部轮廓都要画。

#### (4) 剖切面后面的不可见轮廓线，一般不画出

![后面的不可见轮廓线一般不画](/course-materials/campus-engineering-drawing/figures/img_20261118_090309_gewwwxti.png)

> **为什么可以不画**：剖视的目的就是**消灭虚线**。如果剖完还是一堆虚线，那就白剖了。  
> 所以在剖视图里， **看不见的结构一般省略** （因为已经有别的视图表达它了）。

#### (5) 有助于读图的虚线，也可以画出

![有助于读图的虚线可以画](/course-materials/campus-engineering-drawing/figures/img_20261118_090311_bq35u9qt.png)

> 这是一条**灵活条款**：如果某个虚线**不画出来会引起误解**，那就画。  
> 判据： **画了能帮助看懂 → 画；画了只是添乱 → 不画**。

#### 特别提醒：内孔结构不要漏线、不要多线

> **特别注意对一些内孔结构进行剖切的时候，不要漏线也不要多线。**

![内孔剖切：不要漏线也不要多线](/course-materials/campus-engineering-drawing/figures/img_20261118_090312_7ij9ovyt.png)

**孔、槽剖视图常见错误**

![找错误（1）](/course-materials/campus-engineering-drawing/figures/img_20261118_090314_7d4igx5f.png)

![找错误（2）](/course-materials/campus-engineering-drawing/figures/img_20261118_090316_9l3u23kq.png)

> **改错题的四步查法**：
> ① **查剖面线**：方向对不对？间隔匀不匀？有没有画到孔里（孔里是空的，不能画）？  
> ② **查漏线**：剖切面后面的可见轮廓线画全了吗？台阶、退刀槽、沉孔这些小结构最容易漏；  
> ③ **查多线**：有没有把"已经被切掉的"部分还画着？  
> ④ **查孔口**：孔与外形相交的台阶处，线是否连续、是否多出一个"假底"。

### 五、剖视图的种类（三种）

![三种剖视图对比](/course-materials/campus-engineering-drawing/figures/img_20261118_090225_v896vkd8.png)

#### 1. 全剖视图

> **用剖切面完全剖开机件后所得到的剖视图称为全剖视图。**  
> **全剖视图主要用于外形简单、内部结构复杂的机件。**

![全剖视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090318_w600ynxa.png)

**全剖视图的标注（四件事）**：

> 1. 用**短粗实线**作为剖切符号表示剖切面的位置；
> 2. 用**箭头**表示投射方向；
> 3. 在剖切符号附近标出**字母**，并在剖视图上方标出相应字母。

![全剖视图的标注](/course-materials/campus-engineering-drawing/figures/img_20261118_090320_zl8rxnmr.png)

> **4) 当剖切面通过机件的对称平面，且剖视图按投影关系配置，中间又没有其它图形隔开时，可以省略标注。**  
> （另外： **视图按投影关系配置时，箭头可省略**。）

![可省略标注的情形](/course-materials/campus-engineering-drawing/figures/img_20261118_090322_g32klgu6.png)

![剖视图标注方法](/course-materials/campus-engineering-drawing/figures/img_20261118_090223_72bs6ejd.png)

> **标注"能不能省"的判断树**：
> 
> ```
> 剖切面过不过对称平面？
> ├─ 过 ┬ 按投影关系配置？──是──┬ 中间无其它图形隔开？──是──→ 全省
> │     └─否──────────────→ 标字母，箭头可省
> └─ 不过 ──────────────────→ 剖切符号 + 箭头 + 字母，全标
> ```

#### 2. 半剖视图

> **对具有对称平面的机件进行剖切时，以对称平面为界，将投影图形的一半画成剖视图，另一半画成视图，这种方法获得的剖视图称为半剖视图。**  
> **半剖视图适用于内、外形都需要表达，而形状对称的机件。**

![半剖视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090324_bq76ubz3.png)

**半剖视图的标注**：

> 1. 剖切位置若为**对称平面**，可**不必标注**；
> 2. 剖切位置若**不是**对称平面，则需注明**剖切符号和字母**。

![半剖视图的标注](/course-materials/campus-engineering-drawing/figures/img_20261118_090325_f9jw1z6r.png)

**画半剖视图需要注意的两个问题（）**：

> **1\. 剖视图与视图的分界处应画成中心线，不可画成粗实线；**  
> **2\. 内部形状已表达清楚的，视图中虚线不再画出。**

![半剖的注意事项](/course-materials/campus-engineering-drawing/figures/img_20261118_090327_2xcynilo.png)

半剖用一半视图表达外形，另一半剖视表达内部，分界线为表示对称位置的细点画线。内部结构如果已表达清楚，视图一侧可省略相应虚线。仍需借虚线表达的结构应保留，例如剖视中未显示的小孔。

> 补充： **当机件形状接近于对称，且其不对称部分已另有视图表达清楚时，也允许画成半剖视图。**

![接近对称时的半剖](/course-materials/campus-engineering-drawing/figures/img_20261118_090329_thabu91o.png)

> 还可以**将投射方向一致的几个对称图形各取一半（或四分之一）合并成一个图形**，  
> 此时应在剖视图附近标出相应的剖视图名称。

![合并图形](/course-materials/campus-engineering-drawing/figures/img_20261118_090331_33f2h0gs.png)

| 页码 | 内容 |
| --- | --- |
| p39 | 作业：6-7（左视图）｜ 2026-11-3 |
| p40 | 作业：6-8(2) ｜ 2026-11-3 |

#### 3. 局部剖视图

> **用剖切面局部剖开机件，所得的剖视图称为局部剖视图。**  
> 局部剖视图具有**同时表达机件内、外结构**的优点，适用于**不宜采用全剖、半剖视**的情况。

![局部剖视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090333_bkk14xzl.png)

**画局部剖视图时应注意的三个问题（）**：

> **（1）波浪线不能与轮廓线重合，也不能画在其他图线的延长线上。**

![波浪线注意（1）](/course-materials/campus-engineering-drawing/figures/img_20261118_090335_101pd4q3.png)

> **（2）波浪线不能穿空而过，也不能超出视图的轮廓线。**

![波浪线注意（2）：不能穿空而过、不能超出轮廓](/course-materials/campus-engineering-drawing/figures/img_20261118_090337_w1mgkoxg.png)

![波浪线注意（2）续](/course-materials/campus-engineering-drawing/figures/img_20261118_090339_7ugza4z2.png)

> **（3）当被剖结构为回转体时，允许将其中线作局部剖的分界线。**

![波浪线注意（3）：回转体可用中心线分界](/course-materials/campus-engineering-drawing/figures/img_20261118_090341_omphncsh.png)

> **一句话理解波浪线的本质**：
> **波浪线 = "假想的断裂线"，它必须走在"实实在在的材料"上。**
> 
> - 走在材料上 → 对（它表示"这里是断开的截面"）；
> - 走在轮廓线上 → 错（会和真实棱线混淆，看不出哪条是棱）；
> - 穿空而过 → 错（空的地方没有材料，断了也没意义）；
> - 超出轮廓 → 错（图外没有物体）。
> 
> **口诀：「不贴轮廓、不钻空、不出界、不搭延长线」**。

### 六、剖切面的种类（四种）

#### 1. 单一剖切平面

**（1）平行于某一基本投影面的平面剖切**

> **全剖视图、半剖视图和局部剖视图都是单一剖切平面剖切的图例，并且剖切平面都平行于某一个基本投影面。**

![单一剖切平面（平行于基本投影面）](/course-materials/campus-engineering-drawing/figures/img_20261118_090343_qzr1dl1x.png)

**（2）用不平行于任何基本投影面的剖切平面剖切 —— 斜剖视图**

> 为了表达机件上倾斜部分的内部结构，可以用不平行于任何基本投影面的剖切面剖开机件，  
> 从而**真实地反映机件倾斜部分的内部结构**，这种剖视常称为**斜剖视图**。

![斜剖视图](/course-materials/campus-engineering-drawing/figures/img_20261118_090345_sstnc620.png)

> 这种剖视图一般按**投影关系配置并标注**，但也可以**平移到其他适当的地方**；  
> 在不致引起误解的情况下，也允许将图形**旋转配置**，但必须在剖视图上方**标注出旋转符号**。

![斜剖视图的配置与旋转](/course-materials/campus-engineering-drawing/figures/img_20261118_090346_5s4o97io.png)

#### 2. 几个平行的剖切平面

> 当机件上有较多分布在**几个相互平行平面**上的内部结构的时候，可以采用几个平行的剖切平面剖开机件。  
> 剖切平面**起、迄、转折处**应画出剖切符号并加注字母，剖视图上方应注明相应字母。  
> **各剖切平面的转折处必须为直角，并且剖切平面不得相互重叠。**

![几个平行的剖切平面](/course-materials/campus-engineering-drawing/figures/img_20261118_090348_bzokdqe3.png)

**两条硬规定（易错）**：

> **剖视中剖切平面转折处不画任何图线，并且转折部位不应与机件原有轮廓重合。**

![转折处不画线](/course-materials/campus-engineering-drawing/figures/img_20261118_090350_jilnha2m.png)

> **剖视图内不应出现不完整要素。**如孔、槽、凸台、筋板等结构，不应一部分剖去、一部分保留。

![不应出现不完整要素](/course-materials/campus-engineering-drawing/figures/img_20261118_090352_oiziwpbz.png)

> **为什么"转折处不画线"？**  
> 因为**剖切是假想的**，那个"转折"只是作图时为了"拐个弯去切另一个孔"，它在零件上**并不存在**。  
> 画了线就等于凭空造出一道棱。
> 
> **"不完整要素"这条最容易踩**：如果某个孔正卡在转折处，一半被切到一半没切到，图上就会出现"半个孔"，  
> 这是不允许的 —— **要么让转折点避开它，要么把这个孔整个按不剖处理**。

#### 3. 几个相交的剖切平面

**（1）用两个相交的剖切平面剖切**

> 这种方法适合表达具有**公共回转轴线**的机件，如**轮、盘、盖**等机件上的孔、槽等的内部结构。  
> 画图时要注意将**正垂面剖切到的结构绕交线（轴线）旋转到与侧立投影面平行后**再进行投射。  
> 还应在剖切平面起、迄、转折处画上剖切符号，注写字母，在剖视图上方注明对应字母。

![两个相交的剖切平面](/course-materials/campus-engineering-drawing/figures/img_20261118_090354_dyrny28z.png)

**两个注意事项**：

> **① 位于剖切平面后的其它结构一般仍按原来的位置进行投影。**

![后面的结构按原位投影](/course-materials/campus-engineering-drawing/figures/img_20261118_090356_o7knwdyq.png)

> **② 当剖切后产生不完整要素时，此部分按不剖绘制。**

![不完整要素按不剖绘制](/course-materials/campus-engineering-drawing/figures/img_20261118_090358_60rlhq0z.png)

> **理解「旋转到与投影面平行」**：
> 相交剖切面往往是"一个横着切、一个斜着切"（比如切轮辐上的孔）。  
> 斜着切出来的形状，直接投到 V 面上会**变形**。  
> 所以要把斜切的那部分**绕着两剖切面的交线转一下**，转到"正对着投影面"再投 —— 这样才反映实形。
> 
> **口诀：「斜切的部分要转正再投」**。

**（2）用组合的剖切面剖切**

> 当机件单靠上述某一种剖视方法都不能同时表达出机件上多处结构的时候，可以采用将**几种剖切面组合**起来进行表达。

![组合的剖切面](/course-materials/campus-engineering-drawing/figures/img_20261118_090400_2vhdgknp.png)

> 在必要时可以采用**柱面**对机件进行剖切。

![柱面剖切](/course-materials/campus-engineering-drawing/figures/img_20261118_090402_npyr6frr.png)

#### 4. 其他形式的规定画法（肋、轮辐、薄壁）

**（1）肋板的画法**

> **对于机件的肋板，如按纵向剖切，肋板不画剖面符号，而用粗实线将它与其邻接部分分开。**

![肋板的画法](/course-materials/campus-engineering-drawing/figures/img_20261118_090403_8c13udmv.png)

> 对于机件上的**肋、轮辐及薄壁**等：
> 
> - 如**横向剖切**，仍应**画出剖面符号**；
> - 如**纵向剖切**，这些结构都**不画剖面符号**，并用**粗实线**将它与邻接部分分开。

![肋、轮辐、薄壁的纵横剖切](/course-materials/campus-engineering-drawing/figures/img_20261118_090405_wnfx11fg.png)

**（2）回转体上均匀分布的孔、肋、轮辐结构**

> 当回转体上均匀分布的肋、轮辐、孔等结构**不处于剖切面上时**，可将这些结构**沿回转轴旋转到剖切面上画出**， **不作任何标注**。

![均匀分布结构的旋转画法](/course-materials/campus-engineering-drawing/figures/img_20261118_090407_9e7rvuyz.png)

例如，带均布孔的圆盘可将原来不在剖切面上的孔绕回转轴转到剖切面内再画出，便于表达该类孔的形状。按此规定画法处理时，无须另加旋转标记。
> 
> **别和"肋板"搞混**：
> 
> - **肋/轮辐**纵向剖切 → **不画剖面线** （因为它们很薄，画了会显得"实心"，误导人以为很厚重）；
> - **孔** → 转过来照画（孔是空的，要表达）。

## 6.3 断面图

**断面图**表达剖切处的截面形状，**剖视图**还表达剖切面之后的可见轮廓。以下对照用于区分两者。

|  | 断面图 | 剖视图 |
| --- | --- | --- |
| 画什么 | **只画切口本身的形状** | 切口形状**\+ 切口后面的可见轮廓** |
| 用途 | 表达**某根杆/肋/轮辐的截面形状** | 表达**整个内部结构** |
| 标注 | 按断面位置和配置方式决定 | 通常用剖切符号、箭头和字母，符合省略条件时可简化 |

> 
> 常见两种：
> 
> - **移出断面图**：画在视图外面（最常用）；
> - **重合断面图**：画在视图里面（用细实线，与视图重合）。

## 常用表达方法对照

| 想表达什么 | 用什么 | 关键规则 |
| --- | --- | --- |
| 六个方向的整体外形 | **基本视图** | 位置固定；按位配置可不标注 |
| 视图想挪个地方 | **向视图** | 必须标箭头 + 字母 |
| 只想看一小块外形 | **局部视图** | 波浪线断开；可省 |
| 斜面看不实 | **斜视图** | 加辅助投影面；旋转要标符号 |
| 内部结构复杂 | **剖视图** | 剖切是假想的；其它视图仍完整 |
| 内外形都要看、且对称 | **半剖视图** | 分界线用**点画线** |
| 只局部想看内部 | **局部剖视图** | 波浪线**不贴轮廓、不钻空、不出界** |
| 多个孔在**平行**平面上 | **几个平行剖切面** | 转折处**不画线**；不出现不完整要素 |
| 多个孔绕**公共轴线** | **几个相交剖切面** | 斜切部分**转正再投** |
| 肋/轮辐/薄壁 | **规定画法** | 纵向剖**不画**剖面线；横向剖**要画** |

## 6.5 作图方法与例题

先判断需表达的结构，再选择视图类型或剖切方式。下面按表达方法选择、剖视作图、改错和补线整理。

### 一、题型 A：判断该用哪种表达方法

**判断流程**：

```
要表达的是「外形」还是「内部」？
├─ 外形
│   ├─ 就是标准三视图能搞定 ────────→ 基本视图
│   ├─ 想挪位置 / 图纸排不下 ───────→ 向视图
│   ├─ 只有一小块特殊 ─────────────→ 局部视图
│   └─ 有斜面、不反映实形 ──────────→ 斜视图
└─ 内部
    ├─ 整体都要看、外形简单 ────────→ 全剖
    ├─ 内外都要看 + 形状对称 ───────→ 半剖
    ├─ 只想看局部 / 不宜全剖半剖 ───→ 局部剖
    └─ 孔分布在不同平面上
        ├─ 平面互相平行 ───────────→ 几个平行剖切面
        └─ 绕公共轴线 ─────────────→ 几个相交剖切面
```

局部外形用局部视图表达，倾斜表面的实形用斜视图表达。表达内部结构时，再根据结构的范围和机件的对称性选用全剖、半剖或局部剖。

### 二、题型 B：画剖视图（五步）

> **① 定剖切位置 → ② 画外形轮廓 → ③ 画内部结构 → ④ 打剖面线 → ⑤ 标注 + 检查**

| 步骤 | 动作 | 关键点 |
| --- | --- | --- |
| ① | 选剖切面：过**对称面或孔轴线**，平行于投影面 | 位置错了整张图都别扭 |
| ② | 先画**剖切面后面的全部可见轮廓** | 注意保留台阶、退刀槽 |
| ③ | 画内部孔槽的轮廓（**变成实线**） | 原来视图里的虚线，这里要变实线 |
| ④ | 在**实体部分**打 45° 等距细实线 | **孔里不能打**；同件同向等距 |
| ⑤ | 标注剖切符号 + 箭头 + 字母；检查 | 见下面的检查清单 |

> **剖视图常见错误**：
> 
> 1. **只画一半** （忘了"其它视图仍应完整画出"）；
> 2. **剖面线打进孔里** （孔是空的）；
> 3. **漏画剖切面后面的可见轮廓线**；
> 4. **剖面线方向/间隔不一致** （同一机件必须一致）；
> 5. **主轮廓是 45° 时没改 30°/60°**；
> 6. **忘标注** （或该省的没省、该标的没标）。

### 三、题型 C：改错题（剖视图检查）

> **四查法（按顺序查，一条条过）**：

| 查什么 | 检查内容 |
| --- | --- |
| **① 查剖面线** | 方向对不对？间隔匀不匀？有没有打进孔里？遇 45° 主线改没改？ |
| **② 查漏线** | 剖切面后面的可见轮廓画全了吗？台阶、沉孔、退刀槽？ |
| **③ 查多线** | 有没有画出"已经被切走"的部分？转折处有没有多画线？ |
| **④ 查孔口/台阶** | 孔与外形的交界线是否连续？有没有出现"假底"？ |

先检查剖面线是否只落在实体上，再核对孔口和台阶，最后逐条检查剖切面后的可见轮廓。

### 四、题型 D：半剖 / 局部剖的专项检查

**半剖检查清单**：

| # | 检查项 |
| --- | --- |
| 1 | 分界线是**点画线** （不是粗实线） |
| 2 | 一半剖、一半视图， **分界位置在对称面上** |
| 3 | 视图那一半， **该保留的虚线保留** （没被剖到的结构） |
| 4 | 剖切位置是对称面时， **可以不标注** |

**局部剖检查清单**：

| # | 检查项 |
| --- | --- |
| 1 | 波浪线**不与轮廓线重合** |
| 2 | 波浪线**不画在其它图线的延长线上** |
| 3 | 波浪线**不穿空而过** |
| 4 | 波浪线**不超出视图轮廓** |
| 5 | 回转体处允许用**中心线**代替波浪线 |

### 五、本章易错点总清单

| # | 易错点 | 正确做法 |
| --- | --- | --- |
| 1 | 剖切后把其它视图也画成一半 | **其它视图仍完整画出** |
| 2 | 剖面线打进孔洞 | 孔里是空的， **不画** |
| 3 | 同一机件各视图剖面线方向不一致 | **同向、等距** |
| 4 | 主轮廓 45° 时剖面线仍画 45° | 改**30° 或 60°** |
| 5 | 半剖分界线画粗实线 | 画**点画线（中心线）** |
| 6 | 半剖把视图侧虚线全删 | 未表达清楚的结构**虚线要留** |
| 7 | 局部剖波浪线贴轮廓线 | 波浪线**不能与轮廓重合** |
| 8 | 波浪线穿过孔洞 | **不能穿空** |
| 9 | 平行剖切面转折处画了线 | **转折处不画任何线** |
| 10 | 剖视图里出现不完整要素 | 孔槽凸台**不能一半剖一半留** |
| 11 | 相交剖切面忘了"转正" | 斜切部分**绕交线转到平行于投影面** |
| 12 | 肋板纵向剖切画了剖面线 | **不画**，用粗实线分开 |
| 13 | 均匀布孔只画切到的两个 | 未切到的**旋转到剖切面上画出** |
| 14 | 向视图挪了位置不标注 | 必须标**箭头 + 字母** |
| 15 | 局部视图不用波浪线断开 | 用波浪线（除非本身封闭完整） |

完成剖视图后，核对其余视图中的轮廓和投影对应关系。

## 课堂小结

| 项目 | 要点 |
| --- | --- |
| **基本视图** | 六个：主、俯、左、 **右、仰、后**；位置固定 |
| **六视图位置** | **仰上俯下、右左左右、后在最右** （看的方向与画的位置相反） |
| **后视图** | 与主视图成**镜像** （后视图左边 = 物体右边） |
| **向视图** | 位置**自由**；必须标**箭头 + 字母** |
| **局部视图** | 只画**一部分**；范围用**波浪线** （封闭完整时可省） |
| **斜视图** | 加**辅助投影面** （平行于斜面）；可旋转，需标**旋转符号** |
| **剖视图定义** | **假想**剖开 → **移去**观察者与剖切面之间 → 剩余部分**投射** |
| **假想的后果**  | 一个视图剖了， **其它视图仍完整画出** （不能只画一半） |
| **剖面线** | 45° 等距细实线； **同件同向等距**；主轮廓 45° 时改**30°/60°** |
| **剖面线范围** | 只画在**被切到的实体**上； **孔洞不画** |
| **剖切面位置** | 过**对称面或孔轴线**，平行于投影面 |
| **剖切面之后** | **可见轮廓全画**；不可见**一般不画** （有助读图可画） |
| **全剖** | 全切开；适用**外形简单、内部复杂** |
| **半剖** | 一半剖一半视；分界线**点画线**；适用**内外都要看 + 对称** |
| **局部剖** | 局部剖开；波浪线**不贴轮廓/不钻空/不出界/不搭延长线**；回转体可用中心线 |
| **剖视图标注** | **短粗实线** （位置）+ **箭头** （方向）+ **字母** （对应） |
| **可省略标注** | 过**对称平面** + 按**投影关系**配置 + 中间**无其它图形**隔开 → **全可省** |
| **单一剖切面** | 平行于基本投影面（最常用）／不平行 → **斜剖视图** |
| **平行剖切面** | 转折处**不画线**； **不出现不完整要素** |
| **相交剖切面** | 斜切部分**绕交线转正**再投；后面结构**按原位**投影 |
| **肋/轮辐/薄壁** | **纵向剖不画**剖面线（粗实线分开）； **横向剖要画** |
| **均布孔/肋** | 未切到的**旋转到剖切面上**画出， **不标注** |
| **断面图** （概念） | 只画**切口形状**；剖视图 = 切口 + **后面可见轮廓** |
