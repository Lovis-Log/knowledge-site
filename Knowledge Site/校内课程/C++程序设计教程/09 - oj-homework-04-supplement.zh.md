## A

**1的个数**

统计 `1` 到 `N` 的所有整数中，十进制数字 `1` 一共出现了多少次。按代码先读测试组数 `T`，每组读一个 `N` 并输出一个总数。

- **思路**：写一个拆位函数统计单个整数中 `1` 的个数，再枚举 `1..N` 累加；每组的 `total` 都必须重新置 0。
原解枚举每个数再拆位，时间为 $O(N\log N)$。`N = 0` 时答案为 0。若 `N` 很大，可以按数位计数，时间降为 $O(\log N)$，总数和位权用 `long long` 保存。

对位权 `p`（`1, 10, 100, …`），每一整段 `10 * p` 个数里，当前位恰好有 `p` 个 `1`。设 `high = N / p / 10`，`digit = N / p % 10`，`low = N % p`。完整段贡献 `high * p`，最后一段的额外贡献取决于 `digit`。`digit == 0` 加 0，`digit == 1` 加 `low + 1`，`digit > 1` 加 `p`。例如 `N = 213` 时，十位有两段完整的 `10–19` 和 `110–119`，尾段还有 `210–213`，合计 24 次。

## B

**围圈报数游戏**

`n` 个人围成一圈，从 1 号开始按 1、2、3 循环报数，报到 3 的人退出，求最后留下的人的原始编号。题面给出 `0 < n <= 50`；按代码可连续读多组 `n` 直到 EOF。

- **思路**：这是报数上限为 3 的约瑟夫环。先把编号改成 `0..n-1`，设 `f(i)` 为 `i` 个人时最后留下者的 0 基编号。`f(1) = 0`；每淘汰一人后，从下一人重新编号，旧编号与新编号相差 3，因此 `f(i) = (f(i-1) + 3) % i`。
- **关键**：循环从 `i = 2` 推到 `n`，最后把 0 基编号加 1 换回题目编号。以 `n = 3` 为例，`f(2) = 1`、`f(3) = 1`，输出 2。
- **边界**：`n = 1` 时循环不执行，直接输出 1；复杂度为 `O(n)`，远小于模拟整个报数过程的开销。

## C

**分解偶数为两素数之和**

把一个偶数表示成两个素数之和。按代码可连续读入多个 `n` 直到 EOF，每行输出一组形如 `n=i+(n-i)` 的表示。

- **思路**：从小到大枚举较小的加数 `i = 2..n/2`，同时判断 `i` 和 `n-i` 是否都是素数，找到第一组就输出并 `break`。
- **关键**：素数判断先排除小于 2 的数，再用 `i * i <= n` 试除到平方根；`break` 保证每个输入只输出一种表示，避免多解造成输出超限。
- **边界**：`n = 4` 时输出 `4=2+2`；若 `n = 2`，循环范围为空，不会输出。**待确认**：题面只写“输入一个偶数”，代码却处理到 EOF；请确认是否多组输入，以及 OJ 是否要求输出“较小加数最小”的那一组。代码默认偶数不小于 4；`n` 的范围也会影响逐个试除是否够快。

## D

**计算两圆相交面积**

给定两个圆的圆心坐标和半径，求相交部分面积。按代码每组读六个实数 `x1 y1 r1 x2 y2 r2`，连续读到 EOF。

- **思路**：先求圆心距 `d`。若 `d >= r1 + r2`，两圆相离或外切，面积为 0；若 `d <= |r1 - r2|`，一圆包含另一圆或内切，面积为较小圆的面积 `π * min(r1,r2)^2`；否则是部分重叠。

部分重叠时，两圆心与任一个交点组成边长为 $d,r_1,r_2$ 的三角形。余弦定理给出第一圆中圆心连线与交点半径的夹角。乘以 2 得到两个交点的半径夹角。扇形面积减去带符号的三角形面积，得到圆弓形面积。

$$
\theta_1=2\arccos\frac{d^2+r_1^2-r_2^2}{2dr_1},\qquad S_1=\frac{r_1^2}{2}(\theta_1-\sin\theta_1).
$$

交换两圆半径得到 $S_2$，总面积为 $S_1+S_2$。临界状态附近可将 `acos` 参数限在 $[-1,1]$ 内。先处理同心、内含和相切时，也避免了在 $d=0$ 或半径为 0 时除以 0。

代码只在有面积的分支里设置 `fixed << setprecision(2)`。外切或相离时，是否显示 `0.00` 会依赖前面组是否设置过该格式。若原题要求统一两位小数，可在输入循环前设置一次。

## E

**寻找不同数字组合个数**

统计 `[0, 10^n)` 中，十进制各位数字互不相同的整数个数。按代码可连续读多个 `n` 直到 EOF；例如 `n = 2` 时答案为 91。

- **思路**：按位数分类。1 位数有 10 个（`0..9`）；长度 `L >= 2` 时，首位不能为 0，有 9 种选择，后面的 `L-1` 位从剩余 9 个数字中有序选取，数量为 `A(9, L-1)`，所以总数为 `10 + Σ(9 * A(9, L-1))`。
- 每增加一位，就从尚未使用的数字里选一个。这个乘法过程直接数出各位都不同的数，无需逐个枚举或对重复数字做分类。
- **边界/代码疑点**：`n = 0` 时代码输出 1，对应 `[0,1)` 中只有 0；`n = 1` 输出 10。代码在 `n >= 11` 时直接输出 0，但按示例的累计口径，`n = 11` 时长度 1 到 10 的合法数仍然存在，只是不存在 11 位且各位互异的十进制数，因此这里应继续使用累计结果，而不是归零。**待确认**：题目是否限制 `n <= 10`，以及 `n = 0` 时区间端点如何定义；若允许 `n > 10`，`n >= 11` 的分支属于代码问题，不是题意。

同题见 [第三次作业 I](/books/campus-cpp-programming/11-oj-homework-03/#zh-i)，含 `n = 10` 的累计结果。

## F

**放课本**

把 `n` 本相同的书放进 `k` 张相同的课桌，每张桌可以放 0 到 `n` 本，不考虑摆放顺序，求方案数。按代码每组读 `n k`，连续读到 EOF；代码注释给出的范围是 `1 <= n, k <= 20`。

- **思路**：这是“把整数 `n` 分成至多 `k` 个无序正整数”的整数拆分。设 `dp[i][j]` 为 `i` 本书放入 `j` 张相同课桌的方案数，按“是否至少有一张空桌”分类：
  - 有空的课桌：方案数为 `dp[i][j-1]`；
  - 所有课桌都非空：先给每张桌放 1 本，剩下 `i-j` 本仍分到 `j` 张桌，方案数为 `dp[i-j][j]`。
  因此 `dp[i][j] = dp[i][j-1] + dp[i-j][j]`。当 `i < j` 时，多出的空桌不影响方案，`dp[i][j] = dp[i][i]`。
- **关键**：初始化 `dp[0][j] = 1`（没有书时只有一种放法）和 `dp[i][1] = 1`；课桌相同，所以不能使用隔板法或排列数，例如 `(1,0,2,3)` 与 `(3,1,2,0)` 是同一种方案。
- **边界**：表的大小按 `1..20` 预留；答案最大约为 `p(20) = 627`，`int` 足够。**待确认**：输入是否确为多组 `n k` 到 EOF，以及 `n`、`k` 是否严格不超过 20。

## G

**字典序中第k个数**

把 `1..n` 按字典序排列，输出第 `k` 个数。按代码每组读 `n k`，连续读到 EOF；例如 `n = 13, k = 2` 时输出 10。

- **思路**：把数字看成十进制前缀树，节点 `x` 的子节点是 `x*10` 到 `x*10+9`；字典序就是这棵树的先序遍历。从 `x = 1` 出发，重复 `k-1` 次求“下一个字典序数”：有子节点就下到 `x*10`；否则向右找兄弟，若当前以 9 结尾或 `x+1` 超过 `n`，就先回到父节点再继续。
- `while (x % 10 == 9 || x + 1 > n) x /= 10;` 可能连续上跳多层，随后 `x++` 进入下一个兄弟。每次上跳都对应此前走过的一次下降，因而遍历前 `k` 个节点的总时间仍为 $O(k)$。判断能否下降可写成 `x <= n / 10`，避免 `x * 10` 先溢出。
- **边界**：算法要求 `n >= 1` 且 `1 <= k <= n`，代码没有校验；`k > n` 时输出没有意义。**待确认**：题面只写 `n` 为非负整数，未给 `n`、`k` 的范围；若 `k` 可达很大，`O(k)` 会超时，可先统计每个前缀子树的节点数，整段跳过无关子树，把复杂度降到 `O(log^2 n)` 级别（前提是 `k <= n`，且统计子树时使用 64 位整数避免溢出）。

跳过整棵子树的推导和示例见 [第三次作业 J](/books/campus-cpp-programming/11-oj-homework-03/#zh-j)。
