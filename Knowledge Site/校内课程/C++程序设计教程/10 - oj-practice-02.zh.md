## A

<!-- homework-topic: 分段函数计算 -->

> **题目**　**分段函数计算**
>
> 每组读入一个整数 `i`，按下列分段规则计算函数值，每组输出一行并保留四位小数。
>
> | `i` 的范围 | 计算式 |
> | --- | --- |
> | `i < 0` | `0` |
> | `0 <= i < 10` | `2 * i` |
> | `10 <= i < 50` | `2 * i + 1` |
> | `i >= 50` | `i / 2 + 50`（`i` 是 `int`，按整数除法） |
>
> 输入：多组，每行一个整数，读到文件结束。输出：每组一行，小数点后四位。
>
> 示例：`10` → `21.0000`；`49` → `99.0000`；`50` → `75.0000`。

**方法**　从下往上按「上界」写一串 `if / else if`，最后一段不再判条件。

**为什么这样写**　四段互不重叠，且按区间从小到大排列。`else if` 只在前面所有条件都为假时才求值，所以轮到 `i < 50` 时，`i < 0` 和 `i < 10` 已经被排除，`i` 必然 `>= 10`，下界不用再写一遍。这也是为什么代码里只出现 `i < 0`、`i < 10`、`i < 50` 三个阈值，而不会写成 `i >= 0 && i < 10`——顺序本身就是下界。若把顺序颠倒（先判 `i < 50`），`i = 5` 就会错误落进 `2i + 1` 那一段。

**关键点：整数除法**　`x` 声明成 `double` 并不代表最后一段做了实数除法。`i / 2` 的两个操作数都是 `int`，这一步先按整数算完（向零截断），才把结果赋给 `x`，小数已经丢了。所以 `i = 51` 得到 `25 + 50 = 75.0000`；若题面要求 `x / 2` 的实数结果，应写 `i / 2.0 + 50`，输出 `75.5000`。要么把一个操作数改成浮点，要么在赋值前显式转换，光改左侧变量类型没用。

**输出格式**　`fixed` 与 `setprecision(4)` 必须一起用。单写 `setprecision(4)` 表示「四位有效数字」，`i = 50` 会输出 `75`；加了 `fixed` 才表示「小数点后四位」，输出 `75.0000`。`fixed` 是对流的一次性设置，每轮重复写不影响结果，只是冗余。

**边界**　`i = 10` 落在第三段（因为 `i < 10` 已为假），输出 `21.0000`；`i = 9` 输出 `18.0000`；`i = 49` 输出 `99.0000`；`i = 50` 输出 `75.0000`；`i = -1` 输出 `0.0000`。每组 `O(1)`。

**原始代码**

```cpp
#include <iostream>
using namespace std;
#include <iomanip>

int main() {
    int i;
    double x;
    while(cin>>i) {
        if (i<0) {
            x=0;
        } else if(i<10) {
            x=2*i;
        } else if(i<50) {
            x=2*i+1;
        } else {
            x=i/2+50;
        }
        cout<<fixed<<setprecision(4)<<x<<endl;
    }
    return 0;
}
```

**补充解析**　C++ 的整数除法向零截断，而不是向下取整：`-7 / 2` 得 `-3`。本题第一段直接返回 0，没有让负数参与除法，所以两种取整方式的差异不会暴露；换到允许负数的分段函数时，这个细节必须单独确认。

## B

<!-- homework-topic: 判断闰年 -->

> **题目**　**判断闰年**
>
> 每组输入一个年份，按公历规则判断是否为闰年，输出 `Y`（闰年）或 `N`（平年）。
>
> 输入：多组，每行一个年份。输出：每组一行，一个大写字母。
>
> 示例：`2000` → `Y`；`1900` → `N`；`2004` → `Y`。

**方法**　`year % 4 == 0 && year % 100 != 0` 成立则闰；否则再看 `year % 400 == 0`，成立也闰；两者都不成立输出 `N`。

普通年份能被 4 整除就闰，整百年只有能被 400 整除才闰。第二个条件只可能对整百年为真，因此可合成 `(year % 4 == 0 && year % 100 != 0) || year % 400 == 0`。括号让前两个判断的分组更清楚。

**边界**　`1900`：能被 4 整除但被 100 整除、又不被 400 整除，输出 `N`（这是最容易漏的例子）；`2000` 输出 `Y`；`2004` 输出 `Y`；`100` 输出 `N`。注意 `year % 400` 只对整百年起作用，对普通年份没有额外限制。

**原始代码**

```cpp
#include <iostream>
using namespace std;

int main() {
   int year;
   while(cin>>year) {
    if(year%4==0&&year%100!=0) {
        cout<<"Y"<<endl;
    } else if(year%400==0) {
        cout<<"Y"<<endl;
    } else {
        cout<<"N"<<endl;
    }
   }
}
```

[查看原始 B.cpp](https://drive.google.com/file/d/1Q1bv3Eq7yH_HZXpW7138I7Vq_dsmyhc9/view?usp=drivesdk)

**补充要点**　两个分支都输出 `Y`，可以合并成一个条件；但保持分开写法时，第二个分支的实际含义是「能被 400 整除」，而不是「所有整百年」。若误写成 `year % 100 == 0`，`1900` 会被判成闰年。

## C

<!-- homework-topic: 水仙花数 -->

> **题目**　**水仙花数**
>
> 每组读入一个三位正整数，若它等于各位数字的立方和，输出 `TRUE`，否则输出 `FALSE`。
>
> 输入：多组，每行一个三位数。输出：每组一行，`TRUE` 或 `FALSE`。
>
> 示例：`153` → `TRUE`（$1^3+5^3+3^3=153$）；`100` → `FALSE`。

**方法**　拆出百位、十位、个位，比较原数与三个立方的和。

**为什么这样写**　`n / 100` 取百位、`n / 10 % 10` 取十位、`n % 10` 取个位，是三位数最直接的分法。`n / 100` 只在三位数范围内恰好等于百位；若输入是四位数，这个式子会把前两位一起算进来，结论就不可信了。

**循环怎么工作**　`while (cin >> n)` 一次处理一组，判完立刻输出，读到 EOF 自然结束，不需要先读组数。

**边界**　`153` 满足 `1 + 125 + 27 = 153`，输出 `TRUE`；`370`、`371`、`407` 同样是水仙花数。`100` 的立方和是 `1`，输出 `FALSE`。`999` 的立方和是 `2187`，同样输出 `FALSE`——立方和可以超过三位数，所以不能用「和是否仍是三位数」来代替相等判断。

**原始代码**

```cpp
#include<iostream>
using namespace std;

int main() {
    int n,a,b,c;
    while(cin>>n) {
        a=n/100;
        b=n/10%10;
        c=n%10;

        if(n==a*a*a+b*b*b+c*c*c) {
            cout<<"TRUE"<<endl;
         } else {
            cout<<"FALSE"<<endl;
         }
    }
}
```

[查看原始 C.cpp](https://drive.google.com/file/d/1TmfA8Vr1pMnAjk3lj1WBVMwPW5WFHWVj/view?usp=drivesdk)

**补充解析**　三位数的百位 `a` 一定在 `1–9`，所以 `a*a*a` 最大 729；三个立方和最大 2187，`int` 足够。若把题目扩展成「任意位数的阿姆斯特朗数」，拆位要改成循环，并且必须保留原值用于最后比较。

## D

<!-- homework-topic: 成绩转换 -->

> **题目**　**成绩转换**
>
> 对 `[0, 100]` 内的整数成绩划分等级：`90–100` 输出 `A`，`80–89` 输出 `B`，`70–79` 输出 `C`，`60–69` 输出 `D`，`0–59` 输出 `E`。
>
> 输入：多组，每行一个整数成绩。输出：每组一行，一个大写等级字母。
>
> 示例：`90` → `A`；`89` → `B`；`60` → `D`；`59` → `E`。

**方法**　本地代码把每档的上下界都写全，例如 `i <= 100 && i >= 90`。

从高到低判断各档下界时，前面所有分支的条件都已为假，所以每一支只需要写自己的下界。走到 `i >= 80` 时，`i >= 90` 已经为假，所以这一支只接收 `80–89`；这也是补充解法能把每档的另一个端点省掉的原因。

**边界**　`90` 是 `A`、`89` 是 `B`；`60` 是 `D`、`59` 是 `E`；`0` 是 `E`、`100` 是 `A`。本地代码对 `-1` 或 `101` 不产生任何输出——若题面保证成绩在 `0–100`，这不是问题；若题面要求对越界值给出提示，就是缺分支。另外五个分支都输出 `endl`，多组结果之间不会粘连。

**补充解法**　只写每档下界，判断次数从平均三次降到一至两次，越界处理也更集中。

```cpp
#include <iostream>

int main() {
    int score;
    while (std::cin >> score) {
        if (score < 0 || score > 100) continue;   // 题面保证范围时可删掉
        if (score >= 90)      std::cout << "A\n";
        else if (score >= 80) std::cout << "B\n";
        else if (score >= 70) std::cout << "C\n";
        else if (score >= 60) std::cout << "D\n";
        else                  std::cout << "E\n";
    }
}
```

优势在于每个区间只保留一个端点，`else` 的「前面都不成立」自动提供了下界，不会再出现 `i >= 80 && i <= 89` 这种重复约束。适用条件是各档首尾相接、没有空档；`continue` 只跳过本组输出，回到 `while` 继续读下一组，不必为越界再套一层大 `if`。

**原始代码**

```cpp
#include<iostream>
using namespace std;

int main() {
    int i;
    while(cin>>i) {
        if (i<=100&&i>=90) {
            cout<<"A"<<endl;
        } else if(i>=80&&i<=89) {
            cout<<"B"<<endl;
        } else if(i>=70&&i<=79) {
            cout<<"C"<<endl;
        } else if(i>=60&&i<=69) {
            cout<<"D"<<endl;
        } else if(i>=0&&i<=59) {
            cout<<"E"<<endl;
        }
    }
}
```

## E

<!-- homework-topic: 百位个位交换输出 -->

> **题目**　**百位个位交换输出**
>
> 输入三位正整数，交换百位和个位、十位不动，输出交换后的数。
>
> 输入：多组，每行一个三位数。输出：每组一行一个整数。
>
> 示例：`123` → `321`；`120` → `21`（按整数输出，前导零丢失）。

**方法**　拆成 `a`（百位）、`b`（十位）、`c`（个位），再按新位置的权重拼回去：`100 * c + 10 * b + a`。

**为什么这样写**　拆位再按权重相加，等于把三个数字重新摆到新数位上，十位保持在中间，逻辑和竖式一致。`123` → `300 + 20 + 1 = 321`。

**关键边界：百位为零**　交换后最高位可能就是 `0`。`120` 拆成 `1、2、0`，交换后是 `0、2、1`，按整数算就是 `21`，直接输出会丢掉前导的 `0`；`100` 更是只剩 `1`。本地代码用 `int` 拼数再输出，所以拿到的是 `21` 和 `1`。

**补充解法**　如果题面要求「输出三位」，也就是 `021`、`001` 这种形式，必须按字符位分别打印，而不是先算成一个整数：

```cpp
#include <iostream>

int main() {
    int n;
    while (std::cin >> n) {
        const int a = n / 100, b = n / 10 % 10, c = n % 10;
        std::cout << c << b << a << '\n';   // 120 → 021，天然保留前导 0
    }
}
```

优势是逐位输出，前导零不会经过整数转换，也就不需要 `<iomanip>`；适用条件正是「要求固定三位」。若改用整数权重写法再补零，可以用 `setw(3) << setfill('0') << (100*c + 10*b + a)`，但 `setfill('0')` 是流上的持久设置，后面所有输出都会沿用，若同一份代码还要打印别的数，记得改回空格。

**边界**　`123` → `321`；`120` → `21`（或 `021`）；`100` → `1`（或 `001`）；`101` → `101`（回文，结果与原数相同）；`110` → `11`（或 `011`）。每组 `O(1)`。

**原始代码**

```cpp
#include<iostream>
using namespace std;

int main() {
    int n,a,b,c;
    while(cin>>n) {
        a=n/100;
        b=n/10%10;
        c=n%10;
        cout<<(100*c+10*b+a)<<endl;
    }
}
```

## F

<!-- homework-topic: 计算企业的奖金 -->

> **题目**　**计算企业的奖金**
>
> 按利润分四档累进计奖，利润与奖金的对应关系如下。
>
> | 利润区间 | 奖金 |
> | --- | --- |
> | `profit <= 100000` | `profit × 10%` |
> | `100000 < profit <= 200000` | `10000 + (profit - 100000) × 7%` |
> | `200000 < profit <= 400000` | `17000 + (profit - 200000) × 4%` |
> | `profit > 400000` | `25000 + (profit - 400000) × 1%` |
>
> 输入：多组，每行一个利润值。输出：每组一行奖金，按默认浮点格式输出。
>
> 示例：`100000` → `10000`；`250000` → `19000`；`500000` → `26000`。

**方法**　先记住各档起点上已经攒下的奖金，再加「超出本档起点的那部分 × 本档比例」。

**为什么这样写**　累进计费不是「全部利润乘同一个比例」，而是每一段各按自己的比例算，前几段的钱不会因为进入高档而重新打折。`100000` 处的累计是 `100000 × 10% = 10000`；`200000` 处是 `10000 + 100000 × 7% = 17000`；`400000` 处是 `17000 + 200000 × 4% = 25000`。这三个数就是后面各档公式里的常数项——它们不是背下来的，而是逐档累加出来的，改比例时要跟着重算。

**关键条件**　四个区间首尾相接、不重不漏，所以 `else if` 链能保证每笔利润只走一支。分档点写成 `<=` 还是 `<` 在这里不影响结果：`profit = 200000` 走第二档得 `17000`，若走第三档则是 `17000 + 0 = 17000`，两种算法连续。真正要防的是留下空隙（例如写成 `profit < 100000` 和 `profit > 100000` 而漏掉等号）。

例如利润为 `250000` 时，奖金是 `17000 + 50000 × 4% = 19000`。整数利润也可能算出小数，例如利润为 `1` 时奖金是 `0.1`。若题面要求固定两位小数，加 `fixed << setprecision(2)`。

**补充解法**　档数或比例一改，公式版要重抄常数，循环版只改表：

```cpp
#include <algorithm>
#include <iostream>

int main() {
    double profit;
    while (std::cin >> profit) {
        const double top[]  = {100000, 200000, 400000};
        const double rate[] = {0.10, 0.07, 0.04};
        double bonus = 0;
        double lo = 0;
        for (int k = 0; k < 3 && profit > lo; ++k) {
            const double hi = std::min(profit, top[k]);
            bonus += (hi - lo) * rate[k];
            lo = top[k];
        }
        if (profit > lo) bonus += (profit - lo) * 0.01;
        std::cout << bonus << '\n';
    }
}
```

对非负利润，每轮只处理 `[lo, hi]` 内属于本档的部分；`std::min` 保证利润未到本档上限时只累计到 `profit` 为止。40 万以上的部分按 1% 单独累加。优势是新增档位只需在两张表里各加一项，不必再手算累计常数；`std::min` 在 `<algorithm>` 中。

**原始代码**

```cpp
#include<iostream>
using namespace std;

int main() {
    double profit,bonus;
    while(cin>>profit) {
        if(profit<=100000) {
            bonus=profit*0.1;
        } else if(100000<profit&&profit<=200000) {
            bonus=10000+(profit-100000)*0.07;
        } else if(200000<profit&&profit<=400000) {
            bonus=17000+(profit-200000)*0.04;
        } else if(profit>400000) {
            bonus=25000+(profit-400000)*0.01;
        }
        cout<<bonus<<endl;
    }

    return 0;
}
```

## 方法小结

- 分段函数先按区间排好序，只写每个区间的上界；`else` 的「前面都不成立」就是下界。
- 整数除法在赋值给 `double` 之前就已经截断，类型转换要发生在运算之前。
- `fixed` 管「小数点后几位」，`setprecision` 单独用时管「有效数字」，两者含义不同。
- 多个并列区间优先合并成首尾相接的条件链；分档累进要逐档累加常数，不能整笔乘单一比例。
