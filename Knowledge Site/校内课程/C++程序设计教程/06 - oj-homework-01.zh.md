## A

<!-- homework-topic: 输出特定 ASCII 码字符 -->

**输出特定 ASCII 码字符。** 无输入。依次输出 ASCII 码为 35 和 110 的字符，再换行，结果是 `#n`。

**方法**　`char(35)`、`char(110)` 是显式类型转换，把整数按字符类型送出。

**为什么这样做**　`cout` 对 `int` 和 `char` 的处理完全不同：`cout << 35` 打印的是 `35`，`cout << char(35)` 打印的是 `#`。本题练的就是同一个数值按不同类型输出的差别。`char` 转 `int` 方向则常用于把字符还原成编码。

**边界**　两个字符之间不能有空格，末尾必须有换行。也可写成 `static_cast<char>(35)`。

**原始代码**

```cpp
//输出ASC2码

#include <iostream>
using namespace std;

int main()
{
    cout<<char(35)<<char(110)<<endl;
}
```

## B

<!-- homework-topic: 计算矩形周长和面积 -->

**计算矩形周长和面积。** 读入矩形的长和宽，输出周长与面积，中间用空格分隔。原程序读一组，边长可以带小数。

**方法**　周长是两条长加两条宽，即 `2 * (a + b)`；面积直接 `a * b`。两个变量都用 `double`。

`double` 能读入带小数的边长。若以 `int` 读 `3.5 2`，第一次提取读到 `3`，第二次遇到小数点会失败。

例如长 `3.5`、宽 `2` 时输出 `11 7`。若题面要求固定小数位，可用 `fixed` 和 `setprecision`。

**原始代码**

```cpp
//计算矩形周长和面积

#include <iostream>
using namespace std;

int main()
{
    double a,b;
    cin>>a>>b;
    cout<<(2*(a+b))<<" "<<a*b<<endl;
    return 0;
}
```

## C

<!-- homework-topic: 打印正方形 -->

**打印正方形。** 读入边长 `n`，用 `*` 画一个 `n × n` 的空心正方形。现有实现让相邻格之间留一个空格。

以 `n = 3` 为例，图案如下。

```text
* * *
*   *
* * *
```

**方法**　把图形当成 `n × n` 的字符矩阵，外层循环走行 `i`，内层循环走列 `j`，每个格先决定打 `*` 还是空格。

**关键条件**　`i == 0 || i == n-1 || j == 0 || j == n-1` 就是四条边：首行、末行、首列、末列。落在任一条边上打 `*`，其余打空格。写成一个条件而不是四组 `if`，行列两个方向就自然被覆盖，不需要额外判断角点（角点同时满足两个条件也只打一次）。

**循环怎么工作**　内层每处理一个格，紧接着判断 `j != n-1` 再补一个分隔空格，所以行末不会多出尾随空格。`n = 3` 的一行共 5 个字符位置（3 个格 + 2 个分隔空格），中间那行就是 `*` + 空格 + 空格 + 空格 + `*`，即 `*   *`。整幅图输出 `n (2n - 1)` 个字符，时间 `O(n²)`。

**边界**　`n = 1` 时只有一个格，同时是四条边，输出一颗 `*`；`n = 2` 时每个格都在边上，输出两行 `* *`。`n` 很小时星号间隔仍然成立，不需要特判。

本地代码先打印输入提示，再检查 `n` 是否在 `1–20`。如果题面只要求打印图形，提交时去掉提示语。若题目有多组数据，外层用 `while (cin >> n)` 处理。

以下写法按当前图案规则处理单组合法输入。

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    if (!(cin >> n)) return 0;
    for (int i = 0; i < n; ++i) {
        for (int j = 0; j < n; ++j) {
            cout << ((i == 0 || i == n - 1 || j == 0 || j == n - 1) ? '*' : ' ');
            if (j != n - 1) cout << ' ';
        }
        cout << '\n';
    }
    return 0;
}
```

把 `if / else` 收进一个条件表达式，是为了让「打什么」和「补不补分隔空格」两件事分开，循环体更短，边界判断也只有一处。

**原始代码**

```cpp
//打印正方形
//我不会，使用deepseek

#include <iostream>
using namespace std;

int main() {
    int n;

    // 读入边长，并校验范围
    cout << "请输入正方形的边长（1-20）：";
    cin >> n;
    while (n < 1 || n > 20) {
        cout << "输入无效，请输入 1 到 20 之间的整数：";
        cin >> n;
    }

    // 逐行打印
    for (int i = 0; i < n; ++i) {          // i 表示行
        for (int j = 0; j < n; ++j) {      // j 表示列（第几个星号位置）
            // 第一行、最后一行、第一列、最后一列打印 '*'
            if (i == 0 || i == n - 1 || j == 0 || j == n - 1)
                cout << '*';
            else
                cout << ' ';

            // 除了最后一列，每个位置后面加一个分隔空格
            if (j != n - 1)
                cout << ' ';
        }
        cout << endl;                      // 每行结束换行
    }

    return 0;
}
```

## D

<!-- homework-topic: 数的奇偶判断（习题 2-2） -->

**数的奇偶判断（习题 2-2）。** 连续读入整数，偶数输出 `even`，奇数输出 `odd`，每个结果一行。当前代码读到文件结束为止。

**方法**　判断 `a % 2 == 0`。

**为什么这样做**　只判断「是不是偶数」，剩下的自然就是奇数，不需要第二个条件。用 `a % 2 == 1` 判断奇数则会出错：C++ 的取模保留被除数的符号，`-3 % 2` 得到 `-1`，负奇数会被判成偶数。

**循环怎么工作**　`while (cin >> a)` 每轮先尝试读一个整数，读到就进循环体，读到 EOF 或类型不符时表达式的值为假，循环结束。这正是「不知道有几组」的标准写法，比先读组数更稳。

**边界**　`0` 是偶数；负奇数如 `-3`、`-1` 也走 `odd` 分支。

**更清晰的写法**　三目表达式可以把分支压成一行：

```cpp
while (cin >> a)
    cout << (a % 2 == 0 ? "even" : "odd") << '\n';
```

每组 `O(1)`。

**原始代码**

```cpp
//习题2-2

#include <iostream>
using namespace std;

int main()
{
    int a;
    while (cin>>a) {

        if (a%2==0) {
            cout<<"even"<<endl;
        } else {
        cout<<"odd"<<endl;
        }
    }
    return 0;
}
```

## E

<!-- homework-topic: 最小数 -->

**最小数。** 每组三个整数，输出其中的最小值，一行一个。

**方法**　嵌套三目：先比 `num1` 和 `num2`，胜者再和 `num3` 比。

**为什么这样做**　三个数的最小值只需要两次比较：第一层 `num1 <= num2` 先淘汰掉较大的那个，被淘汰的数不可能比留下的数更小，所以之后只让留下的数与 `num3` 比一次就能定出答案。这比三个数两两比较三次要少一次。用 `<=` 而不是 `<`，相等时取任意一个都对，但同一个表达式里统一用 `<=` 能保证内层两个分支的判断方向一致。

**边界**　三个数相等、含负数、含 `0` 都能正确输出；输入保证三个数时不用担心中途缺数据。

**更清晰的写法**　展开成两步赋值，读起来比嵌套三目直观：

```cpp
int ab = (num1 <= num2) ? num1 : num2;
cout << (ab <= num3 ? ab : num3) << '\n';
```

允许用 `<algorithm>` 时也可直接 `std::min({num1, num2, num3})`（C++11 的列表初始化重载）。每组 `O(1)`。

**原始代码**

```cpp
//最小数

#include <iostream>
using namespace std;

int main()
{
    int num1,num2,num3;
    while (cin>>num1>>num2>>num3) {
         int min;
         min=(num1<=num2)?(num1<=num3?num1:num3):(num2<=num3?num2:num3) ;
         cout<<min<<endl;
    }

}
```

## F

<!-- homework-topic: 逆序输出 -->

**逆序输出。** 从拆位代码推断，每组读入一个非负五位数，按个位到万位的顺序输出五个数字，中间用空格分隔。例如 `12030` 对应 `0 3 0 2 1`。

**方法**　先把五位分别取出来：`a = n / 10000`、`b = n / 1000 % 10`、`c = n / 100 % 10`、`d = n / 10 % 10`、`e = n % 10`，再按 `e d c b a` 输出。

**为什么这样做**　按位输出能保留前导 `0`。若把数值本身反过来（`12030` 反转成 `3021` 再打印），最高位的 `0` 会消失，输出就只剩四个数字。题目要的是五个数字，所以必须拆位、逐个打印。

**组间换行（本地代码的缺陷）**　主版本在 `while` 里输出五个数字后没有换行，多组数据会首尾相连成 `0 3 0 2 11 2 3 4 5` 这样的一长串，明显不对。文件末尾注释里的循环版本补了 `endl`，是正确的形态。修好后：

```cpp
while (cin >> n) {
    for (int i = 0; i < 5; ++i) {
        if (i > 0) cout << ' ';
        cout << n % 10;
        n /= 10;
    }
    cout << '\n';
}
```

`n % 10` 取末位，`n /= 10` 丢掉末位，重复五次正好把五位从低位到高位吐出；`i > 0` 只在第二个数字起补空格，行末不留尾随空格。

**边界**　`12030` → `0 3 0 2 1`；`10000` → `0 0 0 0 1`；`99999` → `9 9 9 9 9`。注意本解法假定输入确实是非负五位数：不足五位时 `a` 会算出 `0`，会多打印一个前导 `0`；输入负数时各位的符号会让拆位结果错乱。每组 `O(1)`。

**另一种写法**　把输入当字符串读，直接从后往前打印，天然保留前导 `0`，也不受位数限制：

```cpp
string s;
while (cin >> s) {
    for (int i = (int)s.size() - 1; i >= 0; --i)
        cout << s[i] << (i > 0 ? ' ' : '\n');
}
```
